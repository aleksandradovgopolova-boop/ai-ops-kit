## Репозиторий

`fixture-events-cli` — маленький Python-CLI (stdlib), команда `list-events` уже существует и
печатает список событий из `events.json` (поля: `id`, `title`, `date` в формате `YYYY-MM-DD`).

## Что сделать

Добавить в `list-events` опциональный флаг `--since <date>`.

### Требования (приёмочные, однозначные)

1. `--since YYYY-MM-DD` показывает только события, у которых `date >= since`. **Граница
   инклюзивна:** событие ровно с датой `since` ВХОДИТ в вывод.
2. Сравнение дат — в **UTC**, календарно по дню (время суток в фикстуре не хранится; сравнение по
   дате как есть, без сдвигов часового пояса).
3. Без `--since` поведение команды не меняется (полный список).
4. Невалидное значение (`--since вчера`, `--since 2026-13-40`, пустая строка) → процесс завершается
   с **кодом выхода 2**, в **stderr** — короткое человекочитаемое сообщение, **без Python-traceback**.
5. Порядок вывода и формат строк не меняются относительно текущего поведения.
6. Изменение покрыто тестами так, чтобы граница (инклюзивность) и ветка невалидной даты были
   проверены явно.
