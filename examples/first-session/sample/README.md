# Greeting sample / Учебный пример приветствия

This synthetic Python project greets a person by name. It has no customers,
production environment, credentials, external services or model integration.

Учебный Python-проект возвращает приветствие по имени. У него нет настоящих
пользователей, production, секретов, внешних сервисов и подключения к модели.

Run the existing test / Проверка: `python3 -m unittest discover -s tests -v`.

Possible next task (not implemented by the offline demo): return `Hello, friend!`
for an empty name and add a regression test. Возможная следующая задача (offline-демо
её не выполняет): для пустого имени вернуть `Hello, friend!` и добавить тест.
