Владелец разрешила засчитывать свои прогоны, подтвердила полезность всех трёх результатов и сообщила: «исправлений не было, подсказок тоже по факту». Корректирующие подсказки и исправления владельцем — **0 по самоотчёту**. Выбор проекта, продуктового приоритета и разрешение на merge учитываются отдельно как решения владельца.

Время календарное, включает ожидания и решения человека. Его начало различается и прямо названо в каждой ячейке; сравнение скорости по этим трём строкам некорректно. Dashboard не является квалификацией версии 4.9.3. Garden P0 сделан до установки Kit, поэтому его эффект Kit не приписывается. У книги принято исследование/планирование; качество живого текста ещё не улучшено доказанным изменением генератора.

## Что доказано и что остаётся открытым

Установки и принятые результаты подтверждены GitHub и журналами сессий. Польза подтверждена владельцем; отсутствие корректирующих подсказок — её самоотчёт. Dashboard имеет продуктовый before/after: Chrome-тест проходит на новой реализации поиска и падает на прежней. Все три проекта имеют принятую работу, однако её вид различается.

Для строгого pass протокола ещё не установлены точные T_result/T_ready и часть событий внутреннего выбора/CLI/тупиков. Объём корректирующей помощи уточнён, но active human minutes, модель/токены/стоимость не измерены. Не подменять недоступное нулём. Независимое техническое ревью текущего исправления Kit не служит задним числом ревью всех исходных продуктовых работ.

Работа #1256 **остаётся открытой**: пределы ≤300с/≤900с не доказаны во всех трёх строках. Долгое ожидание merge само по себе не нарушает ready-порог: это разные события. Полная reference-product qualification Garden и причинный эффект Kit также не заявляются. Новые люди для принятой owner-led когорты не требуются.

## Реальные проблемы, которые ведём в Kit

1. Пустое GitHub expression в shell-комментарии update workflow: GitHub отказал до запуска jobs.
2. Feature coverage пытался коммитить baseline напрямую в защищённый main, получил GH006.
3. CodeQL default JavaScript/TypeScript не соответствовал Python Garden, получил no-source.
4. Local validate не показал заранее правило разделения plan.yaml и JSON/YAML evidence; книга узнала о нём из CI. Отчёт #1257 уже открыт.
5. Классы зрелости/Green из наличия артефактов могли выглядеть как готовность продукта; оговорки в паспортах и отчётах сохранены. Это отдельное трение, не доказательство готового приложения.

Текущий кодовый PR исправляет пункты 1–3. Пункты 4–5 остаются открытыми наблюдениями; не расширять этот PR до изменения продуктовой онтологии.
