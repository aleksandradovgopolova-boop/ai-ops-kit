# Runbook: живой внешний прогон one-feature-end-to-end (P0 №7)

Пошаговый сценарий для **человека со стороны** — не автора кита, без знания его внутренностей.
Это сильнейшее доказательство направления `one-feature-end-to-end` и источник `field_evidence` для
промоута v4.4 в `stable`. Опирается на эталон
[`ONE-FEATURE-ZERO-PIPELINE-SCENARIO.md`](ONE-FEATURE-ZERO-PIPELINE-SCENARIO.md).

## Роли
- **Участник** — проходит путь. Знать про кит ничего не должен: только описывать словами, что хочет
  изменить в продукте. Ему НЕ показывать этот файл до конца прогона (иначе замер «а понятно ли без
  подсказок» испорчен).
- **Наблюдатель** — молча фиксирует по таблице ниже. Не подсказывает; если участник застрял —
  записывает, ГДЕ и на чём (это и есть находка), и только тогда помогает.

## Что понадобится
- Свежий репозиторий продукта с наблюдаемой поверхностью и хоть какой-то реальной задачей — НЕ этот
  репозиторий и не игрушка автора кита. Годится небольшой личный проект участника.
- Установленный runtime (Claude Code с плагином AI Ops, либо `claude` CLI).
- Установка кита **тегом `v4.4.0`** (не через `PYTHONPATH`, не из `main`): это и проверяем.

## Установка (участник, один раз)
1. В репозитории продукта: сказать в Claude Code «установи AI Ops» — плагин проведёт init→doctor→
   onboard. Без плагина — `python3 <kit>/installer/ai_ops.py setup .` с китом, выкачанным на теге
   `v4.4.0`.
2. Ответить на продуктовые вопросы обычными словами (`ai-ops model`) — кит спросит сам.
- Наблюдатель фиксирует: прошла ли установка без чтения кода кита; где участник спотыкнулся.

## Прогон: одна фича, обычными словами
Участник называет ОДНУ конкретную задачу для СВОЕГО продукта одной фразой (например «добавь фильтр
списка по статусу»). Дальше идёт по подсказкам кита, **не открывая YAML и не зная feature id**.

## Лист наблюдения (заполняет наблюдатель)
На каждой границе: что участник сказал · что кит показал · утекла ли техника (feature id / YAML /
имя агента-стадии-гейта / ветка / worktree / SHA / «гейтов N/M») — да/нет · застрял ли участник.

| # | Граница | Утечка техники? | Участник понял без подсказки? | Заметка |
|---|---|---|---|---|
| 1 | описал задачу (intent) | | | кит повторил «Поняла: «…»»? |
| 2 | уточнение (discovery) | | | вопросы человеческим языком? |
| 3 | решение (зачем/как поймём) | | | |
| 4 | спецификация | | | участник НЕ правил файл? |
| 5 | дизайн/UX (если UI) | | | |
| 6 | исполнение | | | размер/риск словами, без веток? |
| 7 | тесты | | | «сценарии проверены», не «N/M»? |
| 8 | ревью (`Verified`) | | | уровень знания, а не счёт гейтов? |
| 9 | PR | | | готовый PR без ручной сборки? |
| 10 | merge | | | |
| 11 | deploy | | | честная зрелость, без вранья? |
| 12 | analytics | | | «подключена» или честно «нет»? |
| 13 | outcome | | | сдвиг метрики X→Y ИЛИ честное «ещё не накоплено»? |
| 14 | что дальше | | | рекомендация появилась в `next`? |

## Критерий успеха (из эталона)
Прогон засчитывается, когда ОДНОВРЕМЕННО: (1) ноль утечек техники на всех границах; (2) `Verified`
показан уровнями знания; (3) `Outcome` показан (сдвиг метрики или честное «ещё не накоплено» с
условием); (4) последняя рекомендация видна в `next`; (5) всё — на установке тегом `v4.4.0`, не через
`PYTHONPATH`; (6) вёл человек со стороны без знания внутренностей.

Границы 11–13 (deploy/analytics/outcome) требуют реального продукта с аналитикой — если её нет, кит
честно скажет «ещё не накоплено»: это НЕ провал прогона, это верный ответ при отсутствии данных.
Провал — если кит ВЫДУМАЛ outcome или показал технику.

## После прогона
- Наблюдатель сводит лист в отчёт `qualification/ONE-FEATURE-EXTERNAL-RUN-<repo>-<дата>.md`
  (дословные реплики кита по границам + итог по критерию).
- Если критерий выполнен на ДВУХ разных внешних репозиториях — это `field_evidence` для минора 4.4:
  запись в `registry/release-claims.yaml -> field_evidence`, после чего 4.4 можно промоутить в
  `stable`. Один репозиторий — уже сильное доказательство направления, но для канала нужно два.
- Владелец засчитывает исходы направления `one-feature-end-to-end` по этому прогону (кит себя не
  судит) — как засчёты #745/#748.
