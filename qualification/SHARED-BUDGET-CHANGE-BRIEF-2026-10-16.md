# Один logical budget на весь прогон

- Результат: существующий max_model_calls ограничивает сумму logical proposer invocations author/implementation/review/fix, включая параллельные packages; один Budget разделяется без новых counters.
- API: ai_ops_run.run(..., budget=shared), parallel_live_dispatch.run_parallel_live(..., budget=shared); существующий execution_pipeline budget принимает тот же объект. signals.execution_budget материализуется ровно на внешней границе. Actual RunPlan сохраняет объявленные serializable limits.
- Пути: shared/budget.py → run_plan/ai_ops_run/fix loop → dispatcher run_options → pipeline author/tool/review; child-config schema объявляет два реально читаемых session_economy поля, config comment честно описывает after-spend USD.
- Инварианты: atomic admission до callback; cap не изобретается; конфликтующие декларации/unknown keys fail-closed; unknown USD не превращается в ноль; generic controller и direct pipeline не обходят лимит.
- Failure modes: malformed/negative/bool/nonfinite cap; counter race; dict создаёт новый счётчик каждой фазе; fix/parallel теряют объект; unsupported USD/duration/physical attempts превращаются в ложный green.
- Доказательство до кода: actual RunPlan сейчас стирает execution_budget; _pipe не передаёт его; consumer из dict создаёт собственный counter. Positive/fail-closed/side-effect tests считают реальные injected callback calls и same-object identity через фазы/пакеты; отказ до calls; исходный checkout не меняется.
- Честная граница: max_model_calls — logical callback admission, не physical retries/fallback, не native session count. USD/duration/unknown requirements отклоняются до calls; per-package отдельные budgets пока unsupported. Существующий child session_economy admission этим API не заменяется и не обходится.
- Не входит: paid/native live fanout, новый ceiling, новая reservation архитектура, spawn/join/cancel adapter, изменение приёмки, релиз, новые модули/пакеты/dependencies. Исполнитель AI; USD/human/acceptance unknown.
- Процесс: targeted/core + применимые ruff/mypy/structure guards; один fresh independent review ≤5/одна коррекция; все17 exact-head CI до normal merge. Local full — лишь по новому конкретному uncovered risk по #1306.
