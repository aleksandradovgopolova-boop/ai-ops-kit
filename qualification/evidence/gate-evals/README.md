# Улики живых прогонов корпуса gate-евалов

Здесь лежат полные ответы судьи (`<case-id>-<n>.md`), записанные живым прогоном
`python3 -m ai_ops_kit.devtools.gate_eval_live --record`. Сами кейсы — в
[evaluations/gates/](../../../evaluations/gates/README.md); там же описано, что корпус доказывает,
а что нет.

**Почему улики здесь, а не рядом с кейсом.** Это стенограммы конкретного прогона кита на
собственных коммитах — тот же род данных, что остальное содержимое `qualification/evidence/`.
Внутри YAML-кейса 85 КБ судейской прозы превращают его в блоб, который человек не открывает: набор
СЛУЧАЕВ стал бы дампом. В поставку каталог не входит (dev-only), как и сам корпус.

**Замер стареет.** Каждая стенограмма верна для названных в кейсе провайдера, модели и даты — и ни
для чего другого. Офлайн-replay воспроизводит по ним РАЗБОР вердикта; устойчивость самого судьи
проверяется только новым живым прогоном.
