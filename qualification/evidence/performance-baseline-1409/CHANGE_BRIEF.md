# #1409 — база времени и памяти

Результат: существующий `bench_performance` воспроизводимо исполняет последовательные серии команд CI/runtime, сохраняет все попытки, время и пик RSS; отказ или несовместимые входы не дают зелёное сравнение.
Затрагиваемые пути: CLI devtools → JSON suite → отдельный процесс измерителя → команда → receipt/logs → явный baseline → сравнение времени/памяти. Старый microbenchmark API сохраняется.
Инварианты: stdlib + существующий host_resource_cli; без второго механизма, автоматической перезаписи базы, новых CI-гейтов, shell=True и оптимизаций. SHA и dirty fingerprint обязательны. Локальная реплика CI не объявляется настоящим CI.
Failure modes: ненулевой exit/timeout; отсутствующая или повреждённая база; пропавшая метрика/команда; другая среда/повторы; занятый или потерянный host-slot; фоновые потомки после выхода команды; прерывание измерителя; рассогласование samples и агрегатов.
Доказательство: лёгкие subprocess-тесты с фактическим marker-файлом и измерением RSS; контролируемая задержка действительно исполняется до проверки красного сравнения; ошибочные/несопоставимые receipts блокируются; прежние unit-тесты и core smoke.
Не входит: оптимизация, новый обязательный CI, изменение общих реестров/плана/FILE_INDEX/CI, запуск тяжёлых серий без отдельного окна. Фактический baseline до такого окна остаётся NOT_RUN.

## Продолжение 2026-10-30

Результат: устранить подтверждённый CI-блокер прежнего PR #1425, сохранив честное различение local/GitHub Actions; явно выбранная невалидная база отказывает до команд; зафиксировать фактический остаток измерений.
Затрагиваемые пути: unit subprocess → `run_suite` → `suite_metadata` → JSON receipt → сравнение; существующий CI fast-1 исполняет тот же тест.
Инварианты: production-определение среды не подменяется ради зелёного; реальные argv и marker остаются доказательством выполнения; release 4.12, CI-политика и пороги не меняются.
Failure modes: inherited `GITHUB_ACTIONS=true` ломает локальное ожидание или сохраняет чужой run id/attempt; Actions-контекст не сохраняется; явно выбранный JSON null принимается за отсутствие базы; фикстура выдаётся за baseline; серия запускается при занятом общем слоте.
Доказательство: сначала воспроизвести падение с `GITHUB_ACTIONS=true`, затем выполнить тест для явно заданных local/Actions и проверить run id/attempt; целевые perf-тесты, critical contracts и ruff. CI logs и загрузка хоста сохраняются отдельно от baseline.
Не входит: новый benchmark framework, оптимизация, принятие шумных данных за базу, тяжёлые прогоны, смена владельца или публикация конкурирующего PR. Изменения подготовлены для продолжения #1425 после передачи ветки.
