# Замер: нить истории продукта — тест 10 вопросов на ии-среде (T1)

Дата: 2026-09-21. Направление: `product-memory-org-intelligence` (цель №1 «Сейчас»).
Повод: внешнее продуктовое ревью владельца — «не расти вширь, а доказать связанным». Ревью просит
взять ОДНУ реальную фичу и проверить, отвечает ли кит на десять вопросов её жизни ИЗ СВЯЗАННЫХ УЛИК,
а не генерацией. Это приёмочный замер (DoD) текущего шага цели, а не новая работа.

## Как мерили

Дочка `ii-sreda` (`/Users/sasad/ii-sreda`, кит установлен). Граф истории собран из реальных
источников кита: `ai-ops graph build .` → 48 узлов, 31 связь. Затем `ai-ops graph gaps .` и
`ai-ops graph trace <feature> .` по фичам. Источник — `intelligence/knowledge_graph.build_graph`
(план, обучение, паспорта функций); граф строится только из объявленного, связь не выдумывается.

## Что показал замер (честно)

**Итог: 1 из 10 вопросов отвечается из улик.** Вердикт `trace` по каждой фиче — `unmoored` (нить не
пришвартована). Узлы всех сущностей в графе ЕСТЬ (goal 2, initiative 2, epic 5, feature 13, metric 2,
release 3, experiment 1, insight 2), но на уровне ФИЧИ существует ровно одно ребро — `эпик →(contains)→
фича`. Рёбер к цели, решению, проверке, результату и уроку у фич НЕТ.

Отвечается из улик:

| Вопрос | Из улик? | Почему |
|---|---|---|
| 6. Что построили | да | эпик содержит фичу (`contains`) |
| 1–3. Зачем / какая проблема / для кого | нет | нет ребра `фича → цель` (и над эпиком нет родителя-цели) |
| 4–5. Гипотеза / почему это решение | нет | нет ребра `решение →(motivates)→ фича` |
| 7. Что доказано / кто проверял | нет | нет ребра `проверка →(reviewed)→ фича` |
| 8. Что после релиза | нет | нет ребра `фича →(targets)→ результат` |
| 9–10. Чему научились / что дальше | нет | нет ребра к уроку/следующему решению |

Общий срез `gaps`: **15 мест, где ценность не подтверждена измеримым результатом** — 8 фич без
результата (`catalog-api-migration`, `dashboard-object`, `generation-quality`, `injection-resistance`,
`library-view`, `local-model-program`, `onboarding`, `skill-runtime`) и 7 результатов, которые нечем
измерить.

## Вывод

Главная продуктовая гипотеза кита («кит помнит, зачем принято решение, что вышло и что дальше») на
ии-среде пока **НЕ доказана**: данные есть как узлы, но не сшиты в нить на уровне фич. Это не провал
инструмента — трассировщик честно отвечает `unmoored` и называет разрывы, а не выдумывает историю.

Замер прямо называет, что достраивать под целью `product-memory-org-intelligence` (это и есть её
следующий шаг, не новое направление): рёбра `цель↔эпик`, `решение →motivates→ фича`,
`проверка →reviewed→ фича`, `фича →targets→ результат →ведёт→ урок`. Когда на ОДНОЙ фиче все десять
вопросов ответятся из связанных улик, DoD из ревью считается взятым; повторный этот замер — критерий.
