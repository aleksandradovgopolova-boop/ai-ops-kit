# Change Brief — проверять исход, не дублировать конвейер

- До правки, 16.10.2026, исполнитель AI. Прямое поручение владельца: «убирай все лишнее в проверках», максимально сократить сроки разработки продуктов агентами.
- Проблема: AGENTS/checklist требуют full-current-python перед каждым коммитом; engineering-cycle §4 требует targeted → core → полный CI один раз. На текущем кейсе один локальный full занял 1999,54 s, ещё три независимые готовые ветки стоят в общей очереди; затем у каждой обязательный PR CI. Это не оценка времени GitHub и не утверждение, что его матрица совпадает с локальной.
- Результат: один непротиворечивый порядок — достаточные целевые регрессии/короткий core локально, затем существующие обязательные проверки CI на точном итоговом head до merge. Локальный полный прогон остаётся для релиза, отсутствующего CI, изменений тестовой инфраструктуры/гейтов или конкретного непокрытого риска.
- Пути: AGENTS.md, существующие engineering-cycle/pre-commit-checklist, newsfragment. Скрипты/состав/условия CI, критерии issue, capability declarations и разрешения не меняются.
- Инварианты: нет merge на частичном/устаревшем/пропущенном CI; draft/targeted не удовлетворяет final readiness; независимое review сохраняется; platform/environment тесты соответствуют затронутому риску; unknown scope не зелёный.
- Failure modes: (1) targeted выдан за full; (2) CI проверяет старый SHA/неполный набор; (3) потеря conditional nightly/release тестов; (4) непройденный CI заменён локальной проверкой; (5) правило неодинаково сформулировано в руководствах.
- Доказательство: сверка фактических групп CI и release/nightly условий; существующие тесты checklist/evidence scopes; один независимый review; неизменённый обязательный CI на итоговом head PR. Новые зеркальные тесты текста не добавляются.
- Не входит: отмена текущего full, изменение состава проверок/приёмки, автоматический merge без полного required CI, обещание универсального ускорения по одному кейсу. Отдельный final-verification intent fix остаётся отдельной продуктовой задачей.
