# Хвост нити истории замкнут реальными данными — ии-среда, 2026-09-17

Работа `close-outcome-learning-loop-with-real-analytics` (направление `product-memory-org-intelligence`).
Механизм нити истории продукта был построен целиком, но её хвост — РЕАЛЬНЫЙ результат фичи и петля
«урок → следующее решение» — упирался в продуктовую аналитику, которой у самого кита нет. Владелец
выбрал замыкать на живом продукте **ии-среда** (`Proektnyy-ofis/ii-sreda`) и подтвердил основу итога.

## Реальная фича и её реальный результат

**Фича `main-health-signal`** (релиз 2026-08-25, PR ii-sreda#629). Проблема, записанная в самом коде
продукта (`.github/workflows/main-health-signal.yml`): 25.08 изменение влили в `main`, оно положило
семь проверок, и это **несколько дней никто не заметил** — красный `main` ничем не сигналил. Фича
делает поломку `main` заметной (заводит и гасит сигнальный issue).

**Метрика (подтверждена владельцем):** здоровье `main` — доля прогонов проверок `ci` на `main`,
завершившихся успехом.

| | значение | окно | источник |
|---|---|---|---|
| baseline | **76%** | август 2026 (месяц инцидента; 232 успеха / 75 падений) | GitHub Actions `ci` на `main` |
| замер | **87%** | сентябрь 2026 (111 успеха / 16 падений) | GitHub Actions `ci` на `main` |
| цель | **90%** | к 2026-09-30 | решение владельца |

**Вердикт ИЗ ЧИСЕЛ (evaluate_outcome): `failed`** — направление верное (76% → 87%), но цель 90% пока
не взята. Это честный «failed», а не «сломано»: улучшилось, но недоказано до цели.

## Воспроизводимость (числа не из головы)

Помесячная доля успеха `ci` на `main` (903 прогона за 3 месяца) снимается напрямую:

```bash
gh api --paginate \
  "repos/Proektnyy-ofis/ii-sreda/actions/workflows/ci.yml/runs?branch=main&per_page=100" \
  --jq '.workflow_runs[] | [.created_at, .conclusion] | @tsv'
# группировка по месяцу: success/(success+failure) → 2026-07 94%, 2026-08 76%, 2026-09 87%
```

## Две честные оговорки

1. **Сводный показатель, не изолированный эффект.** Доля успеха `ci` зависит от многих причин, не
   только от `main-health-signal`. Итог засчитывает владелец (кит себя не судит) — основа подтверждена
   отдельным решением.
2. **Возможный дефект самой фичи (кандидат в следующую работу).** В сентябре было 16 падений `ci` на
   `main`, но **ни одного** сигнального issue не заведено — сигнал, похоже, не срабатывает. Это ровно
   тот «урок → следующее решение», который петля и должна поднимать: «разобраться, почему сигнал молчит».

## Что доказано этой работой, что — хвост

- **Доказано (в ките, на этих реальных числах):** `graph trace <фича>` печатает настоящий сдвиг
  метрики («было 76% → стало 87% при цели 90% — цель пока не взята») и следующий шаг по уроку с
  обоснованием; та же петля показывает предложение в очереди владельца (`inbox`). Проверено красным-до-
  зелёного, без выдуманных чисел.
- **Хвост (за пределами этой работы):** ии-среда работает на старой версии кита (без `graph trace` и
  петли outcome). Живой `graph trace main-health-signal` на самой ии-среде и запись контракта результата
  в её репозиторий возможны только после того, как новый кит доедет до неё релизом. Засчёт исходов
  направления — за владельцем после этого шага.
