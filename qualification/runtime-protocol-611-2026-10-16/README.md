# #611: один сохранённый план потреблён другим native harness

16.10.2026, AI qualification. [Bundle](bundle.json) содержит исходную регистрацию,
неудачную попытку, разрешённое расширение бюджета, настоящий native result,
завершённые command events и сверку хешей. [Код наблюдателя](protocol.source.txt)
вызывает существующий общий CLI, не реализует новый протокол.

## Приёмка и результат

Issue #611 требует тот же план/work-model на другом harness без изменения ядра
через адаптер и протокол status/inbox/next/explain/do. Сохранённые файлы были
созданы controller с runtime=qwen-code; **успешный Qwen inference не заявлен**.
Native Codex 0.163.0 / gpt-5.6-terra прочитал прежний WorkItem, RunPlan, план
продукта, AGENTS и сгенерированный ai-run adapter, затем сам вызвал наблюдатель.
Ядро source `23768068a1783f967783da8b5451295a7819f617` не менялось.

| Intent | Код | Смысл |
|---|---:|---|
| status | 0 | Прочитано состояние сохранённой модели; историческая заявка не новая живая работа |
| inbox | 0 | Прочитан сохранённый входящий контекст копии |
| next | 0 | Прочитан отбор следующей работы из той же модели |
| explain | 0 | Проектное объяснение; generic --feature не делает его карточкой конкретной фичи |
| do | 2 | Реальный отказ intake-incomplete size/risk до внутреннего provider inference |

Внешний native процесс завершился exit0 за 40,690 с. Код 2 означает «не исполнено»;
он сохранён как допустимый отказ протокола, не превращён в доставку или ready.
План, WorkItem и RunPlan сохраняют все три исходных SHA256. Native прочитал
адаптер и использовал общие интенты; source/core не патчились и replan не было.
Успех двух native inference runtimes, выполнение продукта и all-three поддержка
не являются заявлением этого пакета. Приёмка #611 рассматривается в этих
заявленных границах; #1269 остаётся отдельной Claude live qualification.

## Попытки и ограничения

Первая native попытка CLI0.147.0 получила отказ модели до tools: exit1,
16,803 с, токены unknown. После прямого разрешения на единственную коррекцию
до запуска записано расширение бюджета до180с, официальный isolated binary
и ранее проверенная модель; account/credentials/global config не менялись.
Обе попытки сохранены. На успешной: input91480, cached60672 (подмножество),
output773; reasoning79 — часть output. USD, allocation подписки и активные
минуты человека unknown; owner acceptance отсутствует; primary cohort=false.

45 targeted adapter/context tests прошли в сессии исполнения. Проверяемые
наблюдателем команды и хеши stdout включены в bundle; полный stdout с частным
планом продукта сознательно не публикуется. Это ограничивает независимое
восстановление всех содержательных ответов из одного пакета, но не скрывает
коды интентов, прочитанные пути или неизменность модели. Исходные хешированные
receipts сохранены session01; исторические доказательства не переписаны.
