# ChangeBrief: сетевой npm cache только у одноразового runner

Исполнитель AI; инфраструктура качества, excluded из #1243; USD/время владельца unknown.

## Проблема и доказательство до изменения

Доставка Kit4.11.0 в ii-sreda PR1193/run38900622500: Storybook собран за12s,
артефакт выгружен за5s. Post actions/cache оставался in_progress более8минут,
занимая единственный выделенный mac ci-pool и оставляя14проверок в очереди.
Путь кэша задан ~/.npm; на этом хосте10098948KiB. Файл/артефакт сборки не отказал;
это наблюдаемая задержка сохранения, а не выдуманный провал тестов.

## Изменение и границы

В шаблоне preview runner выбирается vars.CI_RUNNER_LINUX или GitHububuntu.
Ограничить network cache отсутствием именно CI_RUNNER_LINUX. Если задан лишь
CI_RUNNER, шаблон всё ещё выбирает hostedubuntu, поэтому лишнего запрета по
CI_RUNNER здесь не нужно. У ii-sreda собственный workflow выбирает оба vars и
его отдельное исправление учитывает оба. Runner selection не меняется.

У собственного runner npm cache сохраняется локально; сборка/артефакт/комментарий,
требования lockfile/script и все проверки остаются. Не чистим общий cache и не
перезапускаем активный runner. Отменять можно только свой superseded run.

## Проверка

YAML и изменённое условие; независимый scoped AI review; обязательный full-current-python
перед коммитом и весь PR CI. Отдельное реальное поле — исправленный preview дочки
без networkcache на ci-pool, затем остальные проверки. Hosted cache path должен
сохраниться. Установленный пакет4.11.0 вручную не меняется, новый шаблон попадёт
в следующий обычный выпуск; специфичный workflow дочки исправляется отдельно.

Реальное повторное поле: childrun38902443491/head79ac539b success, job126s,
network cache skipped. Старый run38900622500 cancelled;878s между началом
postcache и окончанием отмены — не время успешного старого benchmark.
Сборка/артефакт нового прогона успешны. Сравнительный speedup/стоимость не выдумываются.
