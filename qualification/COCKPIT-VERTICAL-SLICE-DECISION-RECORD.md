# Product Decision Record: Экран активной работы

**Дата:** 19.08.2026
**Ссылка на Opportunity Brief:** COCKPIT-VERTICAL-SLICE-OPPORTUNITY-BRIEF.md
**Решение:** принято владельцем

---

## Контекст

Cockpit показывает плитки сессий, но не отвечает на вопросы:
- Что происходит?
- Почему остановилось?
- Что нужно от меня?

Владелец тратит 10-25 мин/день на чтение транскриптов.

## Решение

Создать **панель активной работы** (Active Work Panel) — выдвижную панель справа,
которая показывает контекст текущей сессии без необходимости открывать терминал.

### Что показываем

| Поле | Источник | Обновление |
|------|----------|------------|
| Название работы | workitem.yaml | При смене workitem |
| Feature ID | workitem id | При смене workitem |
| Этап | session telemetry | Каждые 5 сек |
| Статус | session telemetry | Каждые 5 сек |
| Последнее действие | session telemetry | Realtime |
| Требование | session guardrails recommendation | При изменении |
| Следующий шаг | session guardrails recommendation | При изменении |

### Чего НЕ делаем

- Не показываем полный транскрипт (для этого есть терминал)
- Не дублируем LiveSessions (это список ВСЕХ сессий, а не контекст одной)
- Не делаем отдельное окно (панель внутри основного окна)

### Почему это, а не альтернативы

1. **Панель vs модалка:** панель всегда видна, не перекрывает плитки, можно работать с обеими.
2. **Правая сторона vs верх:** справа больше места для текста, верх занят заголовком.
3. **5 сек polling vs websocket:** tmux не даёт событий, polling достаточно для UI-обновлений.

## Исходы

- **Функциональный:** владелец видит контекст сессии за 5 сек без терминала
- **Измеримый:** время от открытия панели до первого действия < 10 сек
- **Технический:** данные берутся из session_telemetry.py через Electron IPC

## Зависимости

- `session_telemetry.snapshot()` — уже есть, даёт данные
- `session_guardrails.recommend()` — уже есть, даёт рекомендацию
- Electron IPC bridge — нужно расширить для передачи telemetry в renderer

## Откат

Если панель не используется (owner не открывает её за неделю) — удаляем.
Это не критический путь, а удобство.

## Связь с North Star

Цепочка: intent (понять что происходит) → decision (открыть панель) → change (панель показана) →
evidence (время до действия) → outcome (владелец работает быстрее).

Умение «показывать контекст сессии» привязано к цепочке — проходит проверку dp-005.
