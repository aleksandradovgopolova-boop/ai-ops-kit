# Дешёвая проверка применимости child-CI — 16.10.2026

Результат: push без затронутых фич и каталог без реестра завершаются с честным сообщением
до установки Python/PyYAML и сетевого клонирования Kit.
Затрагиваемые пути: доставляемые `ai-ops-record.yml` (push/manual, BEFORE fallback,
отбор features и blueprint, запись/коммит) и `ai-ops-feature-catalog.yml` (PR/push/manual,
наличие реестра, генерация/артефакт/коммит); соответствующие существующие тесты.
Инварианты: события, job/check names, набор обрабатываемых фич, пин/права/запись истории
не меняются; ошибка Git не превращается в отсутствие работы; никаких workflow-level paths,
`[skip ci]`, отмен main или ослабления продуктовых проверок.
Коррекция после единственного review: fallback неизвестного BEFORE ищет предыдущий commit;
при его отсутствии явно отказывает. Старый `HEAD~1 || HEAD` зависел от вывода версии Git
и мог выдавать первый push за пустой diff HEAD..HEAD. Подавление вывода неразрешённого ref
воспроизводит этот ложный no-op; нормальный fallback/rename/delete сохраняются.
Failure modes: потеря BEFORE fallback; пропуск rename/delete; ненужный install/clone;
потеря применимой записи; ошибка определения применимости выглядит как зелёный no-op.
Доказательство: реальные Git-фикстуры и shell из шаблонов сравнят старый/новый список,
включая недоступный BEFORE, manual, первую ревизию, rename/delete; применимая фича реально
передаётся в recorder, отсутствие работы не вызывает setup/install/clone. Контракты доставки,
целевые тесты/core smoke, один независимый review, full-current-python и CI.
Не входит: продуктовые тесты/гейты, runtime/installer/защита merge, обновление чужих
custom workflow, релиз и заявления об экономии времени GitHub до измерения.
