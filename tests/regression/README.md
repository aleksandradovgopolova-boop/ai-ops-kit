# Корпус regression-тестов полевых дефектов

Этот слой существует, чтобы связь **«дефект → защищающий тест» жила в СТРУКТУРЕ репозитория,
а не в памяти сессий**. Полевой дефект (`git status` на дочке уронил потолок, джоба 3.9 упала
на импорте, протухший документ не пометился) чинится один раз — но без явного теста ничто не
мешает регрессу вернуть его молча. Здесь у каждого поля-дефекта есть один файл, который
КРАСНЕЕТ ровно тогда, когда фикс откатили.

Это дополнение к unit-слою, а не замена: unit-тесты режут поведение на мелкие функции; regression
фиксирует именно тот угол, которым дефект пришёл С ПОЛЯ (реальный файл на диске, реальный
классификатор путей, реальный запрет импорта), и подписывает его источником.

## Конвенция

- **Один файл на дефект.** Имя — `test_regression_<кратко>.py` (например
  `test_regression_py39_tomllib_import_banned.py`).
- **Докстринг файла обязателен** и называет три вещи:
  1. **Источник** — issue / F-номер / версия / дата поля (откуда дефект известен);
  2. **Симптом** — что именно сломалось у пользователя или в CI;
  3. **Что КРАСНЕЕТ при регрессе** — какое поведение перестанет держаться, если фикс откатить.
- **Тест поведенческий.** Он ИМПОРТИРУЕТ продуктовый код кита и ЗОВЁТ его, а затем `assert`
  на результате. Тест, который лишь читает файл репозитория и утверждает на его форме, сюда не
  подходит — он не ловит регрессию продукта (см. `validate_test_taxonomy`).
- **Не дублировать unit дословно.** Если поведение уже покрыто на уровне функции — взять другой
  угол (сквозной прогон через реальный файл, забытую ветку классификатора, запрет, которого unit
  не касается) или не заводить файл вовсе.
- **Маркер** — `@pytest.mark.regression` (объявлен в `pytest.ini`), на каждой тест-функции или
  через `pytestmark = [pytest.mark.regression]`.

## Инвариант заведения нового файла

Прежде чем закоммитить regression-тест, автор ОБЯЗАН убедиться в двух вещах:

1. тест **зелён** на текущем коде;
2. тест **краснеет**, если откатить фикс (проверяется реверсом руками — временно вернуть дефект,
   увидеть FAILED, вернуть фикс).

Тест, который зелён и на фиксе, и на дефекте, ничего не защищает — он не имеет права здесь жить.
