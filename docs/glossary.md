# Слова, которые встречаются в подробной документации

**Русский · [English](en/glossary.md)** · [Старт](QUICKSTART.md)

| Термин | Простое значение |
|---|---|
| Parent / child | Источник кита / проект, куда он установлен |
| Runtime / executor | Программа, в которой агент выполняет работу, например Codex или Claude Code |
| Provider adapter | Техническое подключение исполнителя к движку; отличается от чтения инструкций репозитория |
| Workflow | Подходящий порядок работы: постановка, выполнение, проверка и результат |
| Gate | Проверка, которая блокирует следующий шаг либо сообщает замечание |
| Evidence | Сохранённый результат проверки, относящийся к конкретной задаче и версии файлов |
| Writer ≠ judge | Автор изменений и независимый проверяющий — разные участники |
| Fail-closed | Сбой обязательной проверки не считается разрешением продолжать |
| Managed | Обновляемые файлы кита в `.ai/managed/`; свои правила — в `.ai/custom/` |
| WorkItem / RunPlan | Запись задачи / план исполнения; сами по себе не подтверждают выполнение |
| Built≠wired | Механизм есть в коде, но не подключён к обычному рабочему пути |
| Qualification | Версия проходит обкатку; это не обещание стабильности всех возможностей |

[Карта возможностей](capability-map.md) хранит детали реализации и способы проверки.
История выпусков — в [CHANGELOG](https://github.com/aleksandradovgopolova-boop/ai-ops-kit/blob/main/CHANGELOG.md), не на первом экране.
