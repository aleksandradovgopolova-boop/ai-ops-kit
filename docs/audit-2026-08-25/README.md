## Главный вывод

Фундамент несущий, развивать можно. Разрыв — между **автоматизированной** дисциплиной (реальной) и **изображённой** (прогнившей вне машинной проверки); плюс кит не до конца применяет к себе планку, которую держит для дочек. Выбор — не «переписать/оставить», а **навести порядок изнутри, не выбрасывая полевой корпус** (strangler-извлечение ядра). Big-bang не оправдан.
