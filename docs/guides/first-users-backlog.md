# Первый внешний запуск: инженерный остаток

Это подготовленный локальный backlog, не обещание готовности и не новая очередь
вместо `planning/plan.yaml`. Источник: запрос владельца 02.11.2026 — русский и
английский пути, простая сессия Codex/Claude, ≤3 команды и проба около 5 минут.
Учёт и приоритеты передаются владельцу плана отдельно.

## first-install-three-commands: подключить кит максимум за три команды

**Что.** Спроектировать доверенный вход для получения кита, изолированной зависимости
и существующего `setup`; предпочтительно одна команда после получения проверенного
источника. Сейчас полный ручной путь — clone, venv, activate, pip requirements, setup.

**Зачем.** Первый пользователь не должен разбираться с Python/PATH прежде чем увидеть пользу.

**Проверяемо.** На чистой macOS и Linux без PyYAML, editable-пакета и глобальных настроек
воспроизведён опубликованный путь ≤3 команд. Зафиксированы время, сеть/зависимости,
commit источника, реальные файлы и отказ при отсутствии сети/целевого Git-репозитория.
Сбой зависимости не показывает успешную установку. Цель времени — проба ≤5 минут
с явно названными предпосылками; измерять, а не заявлять заранее.

**Границы/Источник.** Переиспользовать `installer/ai_ops.py setup`, не плодить второй
установщик. Публичный пакет/URL и модель доверия проверяются отдельно. Не публиковать
выдуманный pipx-пакет, непроверенный curl|sh или замаскированные цепочки из восьми шагов.

## session-language-parity: отвечать и выдавать старт на языке команды

**Что.** Добавить выбранный язык в доставляемый онбординг и необходимые шаблоны;
проверить реальный триггер установки английской фразой. Сейчас входные документы
RU/EN равноценны, но CLI/вопросы/скиллы в основном русскоязычные.

**Зачем.** Международная команда должна пройти тот же путь, не переводя технический вывод сама.

**Проверяемо.** Два новых sample-проекта проходят один маршрут на RU/EN, сохраняют язык
сессии, вопросы владельцу и одинаковые ограничения. Идентификаторы CLI не переводятся.

**Границы/Источник.** Не обещать полную локализацию всех внутренних документов;
не менять полномочия/защиты и не включать hooks как побочный эффект перевода.

## plain-session-entry: сохранить проверенный вход в новой сессии

**Что.** Проверить текущие repo instruction entrypoints для Codex и Claude отдельно
от native adapter; подготовить безопасную доставку ссылок в проектные инструкции,
если существующих маршрутов недостаточно. Сейчас для сессии без подключения дан
явный стартовый запрос с двумя managed-инструкциями.

**Зачем.** Повторная сессия должна начинаться с задачи, а не поиска внутренних команд.

**Проверяемо.** Новая сессия на одном sample commit читает контекст и следует процессу;
смена проекта, compact/resume, отсутствие метода или исполнителя дают конкретный блокер.
Существующий текст владельца сохранён. Инструкция не называется независимым tool-deny.

**Границы/Источник.** #1434 остаётся отдельным незавершённым исследованием;
`standard.team_session` по умолчанию off, Codex 0.147.0 native readiness=false.
Security changes и живые модельные вызовы требуют отдельного согласованного среза.

## first-task-live-proof: проверить пользовательский результат в двух языках

**Что.** После отдельного разрешения на live-вызовы пройти greeting-задачу из
`examples/first-session` на доступном проверенном исполнителе и затем на втором.

**Зачем.** Локальная установка и JSON-разбор ещё не доказывают выполненную задачу человека.

**Проверяемо.** Реальная разница в исходнике, новый тест пустого имени, успешный
регрессионный прогон, текущие отчёты, независимое ревью и честно названные CI/ограничения;
отдельно негативный сценарий недоступного исполнителя. Сохранить версии, стоимость
и время отдельно для RU/EN; не выдавать результаты одного runtime за оба.

**Границы/Источник.** Текущий offline-пример модель не вызывает, код не меняет;
бюджет, credentials и готовность всего native workflow им не подтверждаются.
