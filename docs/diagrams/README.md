# AI Ops — схема «Весь путь» (рабочий черновик)

Понятная документация для человека без техбэкграунда: весь путь продукта с AI Ops —
подключение → фундамент → цикл задач; обязательные документы по восьми контурам; непрерывные
процессы (ревью-обход, исследование, дизайн); задачи, план и приоритеты.

- **Живая версия (артефакт, можно открыть в браузере):**
  https://claude.ai/code/artifact/5b8ae4db-eea2-4b55-8bad-d16cce2cb376
- **Исходник страницы:** [`ai-ops-path.html`](./ai-ops-path.html) (рядом)
- **Сверено с китом:** версия 4.0.0 · сентябрь 2026
- **Статус:** черновик для вычитки — этапы и артефакты реальные, а раскладка «этот файл именно
  на этом шаге» местами трактовка.

## Как дорабатывать из любой сессии

1. Открой сессию Claude Code в `~/ai-ops-kit`.
2. Попроси обновить схему — правится этот файл: `docs/diagrams/ai-ops-path.html`.
3. Публикация в **тот же** артефакт: republish с `url` = ссылка выше (без `url` создастся новый артефакт).

Файл — обычный HTML одной страницей (шрифты с Google Fonts, разметка и данные строятся встроенным
JS из массивов `STAGES` / `CONTOURS` / `ALWAYS` — их удобно править точечно).

Чтобы схема была доступна и с других машин — закоммить `docs/diagrams/` в репозиторий.
