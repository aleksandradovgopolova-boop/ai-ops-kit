# Диагностика неизвестного источника релизного плана

**Результат.** При неполном или изменившемся snapshot пульт сохраняет безопасный код
причины и доступные идентификаторы; готовность выпуска остаётся неизвестной.

**Затрагиваемые пути.** Read-only `capture()` → ошибка snapshot → `release_plan.build()` →
JSON-проекция штатного пульта. Повторная проверка открытых PR используется также перед deploy.

**Инварианты.** Все существующие проверки стабильности, fail-closed и доверенные источники
сохранены. Диагностика не служит доказательством CI/готовности и не меняет semantic fingerprint.
Разрешены только закрытый набор кодов/полей/workflow и положительные числовые PR/run/attempt;
нет payload, URL, exception text, названий jobs, тел issues, токенов или персональных данных.

**Failure modes.** Изменение PR/CI/issues/main; недоступный или повреждённый API;
подмена диагностических полей; утечка чувствительного текста; ложный зелёный результат.

**Доказательство.** Реальные temp-Git fixtures: стабильный snapshot проходит, изменения
действительно происходят и блокируют план с ожидаемым кодом; все ветви финальной сверки,
ошибки коллекций и redaction проверяются отдельно. Проверка неизменности файлов и отсутствия
write API сохраняется. Целевые тесты, core smoke, линтеры и независимый read-only review.

**Не входит.** Восстановление исторических CI bindings, новый trust/recovery contract,
native adapter, rerun/dispatch, модельные вызовы, push/PR/merge/релиз.

**Исходное наблюдение.** На 2026-11-02 опубликованный snapshot publisher `41440750899`,
attempt `1`, source `073d1bfb3ab0cabc884f58fca69e8563b357edeb` уже не содержит
`source_unknown_or_invalid`: target `4.13.0`, `implementation_ci_incomplete`,
`release_bump_pending`, `final_release_evidence_required`. Старый exception не сохранён;
причина сбоя publisher `41430830518` остаётся неизвестной. Завершение CI в окне чтения
совместимо с гонкой, но не доказывает её. Изменение помогает следующей диагностике.
