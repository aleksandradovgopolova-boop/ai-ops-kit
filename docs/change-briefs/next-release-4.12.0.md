3. После отдельного разрешения выпуска подготовить настоящий release PR: owner notes по

   Bump согласует VERSION/manifest/claims/notes, README/ROADMAP и машинный паспорт,
   соберёт CHANGELOG и очистит очередь.
   В этой правке bump и публикация не выполняются.

   применимые валидаторы; `check-full.sh --pr` через общий host-slot на названном Python,
   плюс `pytest -m release_gate` настоящего релизного состояния. Охват —
   `pr-current-python`, не `full-current-python`; nightly/mutation не отменяются.
5. Независимый review итоговой delta и все **17** checks `quality/premerge-checks.json`
   точного head/base: в том числе pipeline-e2e 3.12/3.13, clean-install, upgrade-path,
   macOS. Штатный premerge без admin/обхода. Старый SHA, local receipt, skipped/cancelled
   CI и закрытое issue не подтверждают readiness. Новая база/исходники требуют оценки
   заново; merge последовательно, чтобы не повторить наблюдавшуюся гонку базы.
6. После разрешённого release merge stock `.github/workflows/release.yml` на точном
   **release SHA** вызывает reusable package-quality full-gate, затем реальный mutation,
   drain queue и owner-layer gates **до** автоматического тега/Release. Старый nightly
   не заменяет это. После действия проверить опубликованные tag/Release/SHA.

План пока не означает готовность выпуска: нет frozen source, bump, артефакта и его
проверок. Код #1434 влит, но полная живая приёмка и окно ИИ-среды —

settings/credentials не разрешено. Календарную дату до оценки финального CI и конкретных
blockers не обещаем.

## Change Brief этой правки

**Результат:** ближайший состав и очередь автоматизации сохранены в репозитории.
**Пути:** этот документ, индекс briefs, delivery-plan, ROADMAP, служебный fragment.
**Инварианты:** роли вместо исполнителей, факты статуса, исторические достигнутые цели,
чужие ветки и VERSION сохраняются.
**Failure modes:** устаревший SHA; смешение merged/open; readiness без evidence;
дубли issue; обещание rollout/прав из плана.
**Доказательство:** GitHub tags/PR/issues, штатный assembly, product-model/plan validation,
docs index/strict docs, core smoke, независимый review до merge.
**Не входит:** код автоматизации, release bump/merge, тег/публикация, paid evals и дочки.

## Поправка после полного ready-CI

Полный CI на первоначальном head обнаружил две новые работы под уже достигнутой
целью kit-release-strategy. Локальный прежний набор этот инвариант не охватил.
Исторический зачёт оставлен неизменным; новый запрос владельца выделен в активный
исход evidence-backed-release-planning, обе работы привязаны к нему, ROADMAP
синхронизирован. Ни тест, ни фильтрация достигнутых целей не ослаблены. Для нового
head обязательны прямая регрессия test_next_skips_achieved_goals, roadmap no-drift,
проверки плана/core и новый полный CI. Старые receipt/CI не переименовываются.
