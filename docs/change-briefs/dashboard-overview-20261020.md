# Пульт: компактный обзор продукта

Результат: владелец сначала видит краткое описание AI Ops Kit, затем метрики,
следующую работу и направление; рабочие разделы доступны через навигацию.

Затрагиваемые пути: `dashboard/index.html` → загрузка `data.json` либо встроенного
снимка → существующие render и модальные окна → публикация GitHub Pages.

Инварианты: источники и смысл метрик сохраняются; неизвестность и предупреждения
видны; все прежние действия и идентификаторы работают; узкий экран не обрезает текст.
Описание опирается на README, подробная формулировка по-прежнему приходит из источника.

Failure modes: переполнение сетки; потеря блока при отсутствии фокуса; неверный порядок
с клавиатуры; недоступность раскрытий; скрытое предупреждение снимка.

Доказательство: целевые тесты dashboard, core smoke, ruff; просмотр реальной страницы
до/после, проверка раскрытия и модального окна; обязательные PR CI на итоговом head.
Новая capability не добавляется: три класса проверки покрыты существующими тестами
выбора работы, отказа источника и записи снимка.

Не входит: новые метрики, изменения движка и установка пультов в дочках.
