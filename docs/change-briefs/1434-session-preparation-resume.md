# #1434 — подготовка спецификации до учёта исполнения

- Результат: обычная сохранённая задача получает проверяемую подготовку спеки до запуска; после заполнения та же задача продолжается без повторной постановки.
- Источник: реальный контроль Codex на child `017b8a24`, request `3de6fc100e2344858e2fc58e47a72f34`: `blocked-preflight`, research-spec отсутствует, модель pipeline не запускалась; ручной результат вне процесса не принят.
- Пути: проектный CLI `run`, сохранённое состояние lifecycle, `SessionStart` после resume, штатный spec/preflight, общий managed-канон обоих runtime.
- Решение: подготовка через существующий `spec_levels.create_spec` и проверка coverage до execution-claim; неполное/повреждённое остаётся pending с конкретным шагом, сигналы сохраняются для продолжения.
- Инварианты: исходный prompt/request/root/HEAD/config/managed/source binding прежние; обязательные gates и preset не ослабляются; никакой дополнительной модели на подготовке; реальное исполнение по-прежнему только существующим фасадом.
- Failure modes: ложная готовность пустой спеки; потеря запроса после resume; подмена signals/чужой отчёт; изменение checkout/политики; повтор или гонка уже начатого исполнения.
- Доказательство positive: создать настоящую spec, заполнить её, вызвать CLI без повторной передачи signals, получить реальный процессный side effect и проверенный receipt той же задачи.
- Доказательство fail-closed: отсутствующее/повреждённое/неполное, changed checkout, чужой report и учтённая попытка не вызывают процесс и не становятся accepted; shell-метасимволы остаются данными.
- Environment: реальные FS/Git/подпроцесс, нативный macOS и Git без глобальной identity; только целевые регрессии и короткий core smoke. Сохранённый live trace не выдаётся за новый положительный опыт.
- Не входит: автоматический повтор старой blocked/running попытки без доказанного происхождения, смена provider/model, обход trust/sandbox, платные/живые прогоны, активация child #1243 или включение патча в frozen 4.12. Они остаются отдельными условиями квалификации.
