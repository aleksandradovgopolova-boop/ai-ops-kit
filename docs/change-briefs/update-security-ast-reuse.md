# Один обход AST внутри проверки безопасности update

Результат: сократить реальное время update на прежних релизах, устранив повторные обходы одного Python AST в сканере inline-кода. Профиль настоящего update: 11,71 с под cProfile, из них security_surface 3,86 с, inline_code_lines 3,14 с и три ast.walk по каждому дереву суммарно 1,85 с. Профилирование — диагностический ориентир, не сравнительный замер.

Пути: installer update → security_surface → delivered_surface → scan_injection → inline_code_lines → Python parser. Те же публичные пути scan_repo/security_pack и загрузка scanner по файловому пути также должны работать. Дерево парсится по-прежнему, один локальный список узлов в прежнем порядке переиспользуется подсчётом связываний, проверкой затенений/перезаписи и поиском последовательностей аргументов.

Инварианты: все узлы и прежние правила обходятся; решения, строки и порядок находок не меняются. Conservative fallback для неразбираемого Python сохранён. Список живёт только во время проверки одного файла — глобального кеша и reuse между файлами/версиями нет. Код установщика, миграции, checksums, smoke, security gates, таймауты, CI и весь корпус релизных тегов сохраняются.

Failure modes: одноразовый iterator вместо списка теряет второй проход; AST меняется между проходами; затенение/перезапись имени пропускается; находки следующего файла берутся из прошлого; ухудшается память из-за удержания AST после анализа.

Доказательство: существующие positive/fail-closed/side-effect security tests; счётчик обхода с проверкой реальной находки; последовательные разные входы; полный before/after corpus parity по Python/shell-файлам репозитория. Сопоставимый замер реальных update со всеми 23 версиями, с равными исходами/числом CLI-вызовов и сверкой security_surface/доставленных файлов (кроме изменённого модуля). Время update и всего корпуса показывается отдельно. Core smoke, применимые проверки, независимый review и все обязательные CI точного head.

Не входит: изменение семантики сканера или AST-компактора, in-process подмена update, уменьшение корпуса/набора проверок. Цена: временный список ссылок на узлы одного уже разобранного AST, освобождается после анализа файла.
