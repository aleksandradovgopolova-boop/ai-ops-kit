# Выборочные проверки при динамических зависимостях

21.10.2026, #1321. Прямое поручение владельца: ускорить Kit и дочки, без сравнительных
прогонов и повторных перепроверок. Пульт исключён из работы.

**Результат.** Динамический импорт в постороннем тесте не запускает весь корпус автоматически.
К затронутым тестам консервативно добавляются все динамические загрузчики и их тестовые
потребители: каждый загрузчик считается потенциальным потребителем любой изменённой программы.
Быстрая команда Kit использует существующий impact runner по умолчанию.

**Пути.** repo_graph → verification_tiers → локальный impact CLI и evidence_collector дочки;
check-fast без аргументов → полный diff ветки и рабочей папки → существующие receipts.

**Инварианты.** Динамические потребители не исключаются. Непрочитанное дерево, symlink,
ошибка разбора, загрузчик без тестовых потребителей, неявные pytest fixtures/plugins,
JS aliases/re-exports, неизвестный runner и критические пути
сохраняют full-fallback. Merge/release сохраняют финальный набор. Старый явный --impact и
передача pytest-аргументов совместимы; --all выбирает прежний весь быстрый набор.

**Failure modes.** Потерянный динамический потребитель; алиас/транзитивный импорт;
ошибка обхода дерева; неполный diff после коммита; неподдержанный runner дочки.

**Доказательство.** Один целевой прогон: выбор статических и динамических потребителей,
реально исполненная регрессия скрытого импорта, отказы при неполном дереве и неизвестной базе,
передача выбранной команды коллектору дочки. Независимый review итоговой delta.
Новые performance benchmarks и широкие повторные локальные прогоны не входят.

**Исполнено.** Целевой набор шести модулей: 117 passed, CPython 3.14; ruff PASS.
Независимый review выявил неявных потребителей pytest fixtures/plugins; для них сохранён
full-fallback и добавлены целевые регрессии. После исправления прогоняются только эти регрессии
и проверки неполного обхода дерева. Широкий локальный прогон не заявляется; итоговый PR проходит
существующий CI. Перенос в дочки выполняется штатным обновлением Kit; прямых изменений дочек нет.
