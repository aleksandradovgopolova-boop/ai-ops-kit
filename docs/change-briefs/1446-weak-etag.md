# Пульт принимает подтверждение GitHub при смене префикса ETag

После слияния #1605 две публикации не смогли сверить исходные данные. На настоящей странице запусков docs.yml для 79a89340 первый ответ 200 содержал слабую метку. На повторный запрос с If-None-Match сервер вернул 304 с той же непрозрачной строкой в кавычках и без префикса W/. Побайтовое сравнение всего заголовка отклоняло эту пару.

В соответствии с RFC 9110 §13.1.2 сравниваем значения меток без необязательного префикса W/. Существующие проверки адреса, авторизации, тела и кода ответа сохраняются. Другой идентификатор, несколько меток и некорректный синтаксис оставляют сверку заблокированной. Проверим обе смены префикса, чувствительность идентификатора к регистру и реальный ответ GitHub. Исходная страница плана не содержит заголовков неудавшихся запросов. Тот же дефект воспроизводится независимо.
