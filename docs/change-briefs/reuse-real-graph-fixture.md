# Сократить повторную подготовку реального графа в тестах

Результат: сократить исполнение test_repo_graph без удаления тестов или assertions.
Пути: модульная pytest fixture → build_graph реального кита → глубокая копия на каждый тест.
Инварианты: все прежние node IDs и assertions выполняются; свой mutable граф на каждый тест;
неизменные production source, markers, CI groups и обязательные checks.
Failure modes: тест портит общий граф; незаметно пропущена проверка; ошибка builder стала PASS.
Доказательство: изоляция копии; те же pytest outcomes; builder вызывается 3→1;
сопоставимый ABBA замер тех же node IDs на одном snapshot + независимое review.
Не входит: глобальный cache, session fixtures, снижение CI или подмена реальной сборки графа.
Baseline-профиль: три real-graph tests — 3 passed in 6,41 с, по 2,06–2,14 с на build.
