# #1434 — проверка безопасности по содержимому принятого коммита

## Причина и результат

При повторной проверке задачи pipeline передавал базу, а список файлов вычислялся до текущей HEAD. Текст читался из рабочей копии. Поэтому на один и тот же SHA могли влиять последующая правка, удаление файла или смена ветки. Для доменной проверки источником становятся Git-объекты проверяемой ревизии. Отчёт сохраняет точные ревизии. Область ручного сканирования рабочей копии задаётся отдельно её существующей командой.

## Проверки и границы

Проверяем обычный и агрегированный вход, первый коммит, кириллический путь с пробелами, смену HEAD, удаление, отсутствие объекта и отсутствие записи в рабочее дерево или индекс. Условия блокировки доменов сохраняются. Успех этой проверки не подтверждает применимость отдельных находок или командную приёмку.
