# Пульт показывает найденные факты — 20.10.2026

Результат: вместо общего «нет данных» видны результаты проверок текущего main,
опубликованный выпуск и принятые работы в дочках. «Состояние продукта» удалено по
запросу владельца, согласованная трёхрядная компоновка сохраняется.

Затрагиваемые пути: сборщик → GitHub Actions runs/jobs и Releases → data.json и
встроенный снимок → пульс/подробности; полевой readout и сентябрьские наблюдения →
метрики/подробности; workflow публикации → обновление после завершения CI.

Инварианты: результаты относятся к точному SHA и последней попытке; наличие тестов
не равно их прохождению; разные когорты не смешиваются в общую медиану; неизвестные
расходы/переделки не становятся нулём; истёкшее окно не означает отсутствие дефектов.

Failure modes: API недоступен; неполная пагинация/набор jobs; старый SHA или попытка;
преждевременный зелёный до конца CI; устаревший текст про открытые окна.

Доказательство: positive на полном наборе результатов; fail-closed на ошибках,
пропусках и неверном SHA; сборка записывает реальные источники в снимок; целевые
тесты, короткий core smoke, свежий независимый review и применимый CI итогового head.

Не входит: новые замеры владельца, ретроспективный ROI, изменения дочерних репозиториев,
оценка здоровья продукта зелёным по трём разнородным принятым работам.
