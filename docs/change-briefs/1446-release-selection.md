# Почему работа вошла в ближайший выпуск

**Результат.** В машинном плане и в разделе предстоящего выпуска владелец видит текущую веху, порядок работ по приоритету цели и причину решения по каждой из них. Правило `candidate_limit: 0` включает только код, уже попавший в основной репозиторий.

**Пути.** Обычный `release_plan.build` получает текущую веху, цели и работы из `planning/plan.yaml`. Закрытые работы читаются из `history/plan-history.yaml`. Привязки к составу идут через `pr` работы или фактические `closing_issues` слитого PR. Пульт получает результат вместе с существующим JSON плана.

**Инварианты.** Полный журнал коммитов сохраняется. Решение об отложенной задаче действует только для своей версии. Приёмка владельцем, готовность выпуска и право публикации остаются самостоятельными фактами. Смена оформления пояснения сохраняет проверяемость предыдущей публикации и не создаёт сообщения о смене состава.

**Основные отказы.** Для работы с неизвестной целью нельзя присваивать ранг. Без вехи или валидной связи нельзя приписывать изменение её целям. Слияние из прошлого цикла не доказывает включение в текущий. Незавершённая задача или заявление `done` без слитого кода не расширяют выпуск. Для пустого или повреждённого среза нельзя показывать отбор активного выпуска.

**Доказательство.** Регрессии проверяют сортировку по действующему приоритету, фактические связи и несовпадение цикла отложения, неизвестную область, сохранность коммитов и входных данных, прежний отпечаток публикации. Отдельно проверяются вывод пульта, линтер и core smoke.

Публикация релиза и доставка обновлений в дочерние проекты за пределами этого изменения.

## Уточнение после независимой проверки

Архив допускает ссылку на PR в качестве места проверки результата работы. Отбор обязан сохранить состав при такой записи. В качестве связи можно взять положительный номер либо точное совпадение ссылки с наблюдаемым PR этого репозитория. Иные формы и непроверенные поля отдельной работы дают неизвестную связь. Для активного плана с единственной целью действует канонический вывод цели при отсутствии поля. Архивная работа без цели не наследует нынешнюю цель. Регрессии сравнят полный журнал, готовность, отпечаток и настоящие связи; недостоверные данные самого GitHub и повтор идентификатора работы по-прежнему блокируют расчёт.
