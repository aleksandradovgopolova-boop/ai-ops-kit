# Продолжение ожидания проверок без повторной команды владельца

При ожидании CI для #1608 запрос к GitHub вернул ошибку подключения. Процесс
ожидания завершился. После восстановления связи работу продолжил человек новым
сообщением. Команде premerge нужен штатный режим ограниченного ожидания.

При явном выборе ожидания команда повторяет чтения при временной недоступности
GitHub и незавершённых проверках. Каждая попытка заново сверяет тот же PR, head,
базу, независимое ревью и действующие проверки. Для слияния нужны два совпавших
допуска подряд. Часы монотонные, длительность чтения ограничена остатком времени.
Отказ в доступе, ошибка проверки, смена привязки или истечение времени завершают
команду. Запрос на запись выполняется однократно вне цикла. Неизвестный исход
записи требует отдельной сверки состояния PR. Без параметра сохраняется один
проход. Проверки охватывают восстановление чтения, ожидание CI, смену базы,
предел времени, отказ и число фактических обращений к операции слияния.
