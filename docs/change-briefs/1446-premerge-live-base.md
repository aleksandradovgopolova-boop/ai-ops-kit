# Проверка фактической базы перед слиянием

При проверке состава выпуска 4.16.0 сервер вернул для PR #1563 и #1567 базу, отличавшуюся от первого родителя их squash-коммитов. Все 17 проверок #1567 запускались на дереве 53a36b22, а в main попало d93cdc94.

Перед выдачей допуска premerge сверяет SHA ветки main с SHA базы в PR, CI и квитанции независимого ревью. Повторная проверка при слиянии читает ветку заново, последним запросом перед командой merge. Расхождение, ошибка API или неполный ответ останавливают операцию.

Тесты воспроизводят устаревший снимок PR и продвижение main во время второй проверки. Проверяется отсутствие команды слияния при отказе. Положительный тест подтверждает чтение точной ветки и сохранение проверки head.

GitHub принимает ожидаемый head в команде merge. Между последним чтением main и серверным слиянием сохраняется короткое окно гонки. Историческая приёмка ранее слитых коммитов ведётся отдельно.
