# Первый внешний пользователь: русский и английский старт

Результат: две равноценные витрины и инструкции. Человек понимает, зачем нужен кит,
что сделать один раз и как начать следующую задачу в Codex/Claude обычными словами.
Локальный пример показывает действительный результат без вызовов моделей.

Затрагиваемые пути: README RU/EN → quickstart RU/EN → установка из проверенного
checkout → синтетический Git-проект → доставленный CLI → диагностика/контекст;
ссылки на examples, углублённую документацию и CONTRIBUTING RU/EN.
Исполняемые пути движка, установщика, настройки безопасности и публикация не меняются.

Инварианты: содержание двух языков равноценно; язык сессии — требование к ответам,
не обещание локализации CLI. Установка/инструкции репозитория не доказывают готовность
native provider adapter. #1434 остаётся readiness=false до независимого tool-deny
при hook failure. Действующая лицензия читается из LICENSE; контакт из #1471
не дублируется. Очередь, ROADMAP и архитектуру ведёт другая работа.

Основные failure modes: выдуманный installer URL; модельный вызов в offline-примере;
изменение настоящего проекта/домашних настроек; ложное обещание автозапуска/готовности;
дрейф RU/EN или ссылки на отсутствующие файлы.

Доказательство: воспроизвести пример в новом временном Git-репозитории, проверить
доставленные файлы и машинный вывод, не принимать nonzero за успех; проверить запрет
перезаписи/изменение managed-файла на отдельной копии, зависимости и ссылки; выполнить
целевые существующие тесты документации/установщика и core smoke; независимый read-only
review итоговой delta. Это проверка примера, а не живая приёмка Codex/Claude.

Не входит: push/PR/merge/release, metadata, внешние публикации и приглашения,
провайдеры/модельные вызовы/расходы, native adapter, security changes, перевод всей
внутренней документации или CLI. Незаконченные инженерные шаги — отдельный backlog.
