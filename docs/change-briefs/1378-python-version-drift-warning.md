# Change Brief — предупреждение о дрейфе версии Python local↔CI, 26.10.2026

Результат: перед пушем человек видит предупреждение, если локальный интерпретатор по minor-версии
расходится с полом CI (`requires-python`). На машине владельца это 3.14 против 3.12: зелёный
локальный прогон переставал предсказывать зелёный CI и рождал лишний круг local-green → CI-red
(issue #1378, правило памяти проекта «разница версий не должна рождать повторы»). Теперь расхождение
названо рядом с остальными предупреждениями честности окружения, с подсказкой прогнать контур на
полу CI.

Затрагиваемые пути: `scripts/check-full.sh` и `scripts/check-fast.sh` → локальный цикл проверок
(вызов advisory тем же `$PYTHON`, которым идёт прогон); новый `ai_ops_kit/devtools/python_drift.py`
→ сравнение minor local↔floor и текст предупреждения; `pyproject.toml` `requires-python` → ЕДИНСТВЕННЫЙ
источник пола (читается через `validate_python_compat.declared_floor`, не зашивается второй раз).

Инварианты: проверка АДДИТИВНА и НЕБЛОКИРУЮЩАЯ — код возврата всегда 0, скрипты зовут её через
`|| true`; разница версий НЕ мешает локальной работе (правило владельца первого класса). Пол
`requires-python` и любые ворота/маркеры НЕ меняются и НЕ понижаются. Пол остаётся
единственным источником истины.

Основные failure modes: сделать предупреждение фатальным и заблокировать цикл; зашить пол
вторым литералом и разойтись с pyproject; шуметь при совпадении minor и быть заглушенным;
сломать окружение без pytest (проверка идёт после названного отказа check-*); притвориться,
что предупреждение = запуск на полу (это рекомендация, не прогон).

Доказательство: `tests/unit/test_python_drift.py` — positive (minor расходится → предупреждение
называет пол), fail-closed (minor совпал → тишина; patch-разница не дрейф), side-effect (пол
читается из pyproject через `declared_floor`; CLI возвращает 0 даже при дрейфе — запуск реальным
интерпретатором). Guard `test_local_check_mirrors_ci.py` остаётся зелёным (advisory-вызов не
ломает быстрый цикл). ruff на изменённых файлах, `validate_python_compat`.

Не входит: понижение пола `requires-python`, изменение версии CI, изменение любых ворот/маркеров,
автоматический перезапуск контура на полу, установка второго интерпретатора, замер before/after
числа кругов (отдельный пункт приёмки issue — вне этого аддитивного изменения).
