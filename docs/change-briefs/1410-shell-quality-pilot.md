# #1410 — ShellCheck/shfmt: отдельный наблюдающий контур

Результат: все отслеживаемые `.sh` получают воспроизводимую проверку ShellCheck/shfmt; полный долг виден отдельно от нарушений в изменённых скриптах.
Затрагиваемые пути: новый `scripts/check-shell-quality.sh` → Git inventory/diff → два внешних CLI; отдельный `.github/workflows/shell-quality.yml` → закреплённые CLI → полный отчёт и проверка изменённых файлов; [shell policy](../agent-guides/shell-policy.md) и целевые тесты; append-only ссылка в индексе brief для достижимости обоих документов.
Инварианты: база `02fe0cf74e121b7ececcf72385b07335226a75f4`; существующие wrappers, package-quality, обязательные проверки и их настройки не меняются; скрипты не исполняются и не переписываются; инструменты не устанавливаются локальной командой; Bash 3.2/POSIX различаются явно.
Failure modes: потерянный файл (включая скрытые каталоги/пробелы); отсутствующий/неверной версии CLI; недоступная база/ошибка Git; нарушение скрыто за общим старым долгом; проверка меняет/исполняет исходник.
Доказательство: реальные временные Git-деревья и CLI-процессы — полный/изменённый inventory, ненулевой исход на нарушение/сбой, неизменность файлов и отсутствие исполнения; нативный Bash 3.2 smoke; целевые pytest, core smoke, lint и независимое read-only review.
Не входит: перенос бизнес-логики старых wrappers, их механическое форматирование, повтор #1422, blocking rollout/required checks, закрытие всего #1410, публикация/PR/выпуск.

Первичные источники версий сверены 29.10.2026: [ShellCheck v0.11.0](https://github.com/koalaman/shellcheck/releases/tag/v0.11.0), [shfmt v3.14.1](https://github.com/mvdan/sh/releases/tag/v3.14.1). SHA256 артефактов берутся из официальных expanded_assets этих релизов; runner проверяет версии независимо от установки.
