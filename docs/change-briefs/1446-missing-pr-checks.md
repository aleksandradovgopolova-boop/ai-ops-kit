# Какие изменения удерживают выпуск

В опубликованном плане 4.16.0 на f81d8f5f у трёх слитых PR не подтверждены проверки. Владельцу предлагается «завершить проверки и зависимости», хотя номера PR уже есть в том же плане.

Проекция сообщения должна назвать слитые PR без подтверждённого CI. Пульт и штатная сводка Actions читают это сообщение. Перечень берётся из состава текущего выпуска, с упорядоченными номерами и пределом длины. Если подтверждённой привязки к PR нет, сообщение не подставляет номер. Отсутствие свидетельства не означает провал тестов. При других причинах остановки сохраняется прежнее сообщение.

Проверим смешанный набор слитых и открытых PR, отсутствие привязки, длинный список и фактический вывод сводки. Обновление текста сохраняет условия готовности, публикации и уведомления.
