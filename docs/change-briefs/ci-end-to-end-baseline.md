# Change Brief — Baseline CI всего пути (#1321, срез 3)

**Результат.**
Для самого Кита измерена CI-половина сквозного цикла проверок: на точных SHA разложены
wall / queue / execution / критический путь по контурам (`docs`, `pr-smoke`, `package-quality`)
и названы доказуемые причины повторов. Это опора в числах для последующих срезов #1321, а не
ускорение и не сравнение «до/после».

**Затрагиваемые пути.**
- Документация замера: `qualification/CI-END-TO-END-BASELINE-2026-10-26.md`.
- Доказательства: `qualification/evidence/ci-end-to-end-baseline-20261026/` (`report.json`,
  `commands.txt`, `raw-jobs/`, `runs-context-40.json`).
- Индекс change-brief'ов и очередь newsfragments (по одной строке).
- Исполняемого кода нет — только read-only чтение GitHub Actions через `gh`.

**Инварианты.**
- wall / execution / queue / критический путь не смешиваются; параллельные jobs не суммируются в стену.
- Неизвестное помечено `null`, а не нулём; «не запускалась ≠ прошла».
- Причина повтора называется только если выводима из метаданных прогона; иначе — «не определимо».
- Ни один workflow не запускается, не перезапускается и не отменяется; CI дочек не затрагивается.

**Основные failure modes.**
1. Сумма параллельных jobs выдаётся за стену (завышает ~3,5×) — снято явной метрикой `sum_parallel` «не использовать как стену».
2. Класс раннера принимается за фактические CPU/RAM/workers — помечено `null`.
3. Причина падения/повтора додумывается без лога — явно «не определимо из метаданных».
4. Точечные наблюдения выдаются за p95 — p95 помечен недоступным при малом n.

**Доказательство.**
- positive — `report.json` содержит сырые per-run/per-job timestamps и производные метрики на 5 SHA.
- fail-closed — пропущенные jobs (`security-scan`, `delivered-footprint` на push) идут как `null`, не 0; падение `package-quality` на `f28fc143` зафиксировано как failure, а не скрыто.
- side-effect proof — `commands.txt` воспроизводит сбор; `raw-jobs/` хранит исходные ответы `gh`.

**Не входит.**
Ускорение, изменение проверок, политика объёма (отдельные срезы), CI дочек, step-level тайминг,
cache hit/miss, p95, бюджеты до/после. Задача #1321 остаётся открытой.
