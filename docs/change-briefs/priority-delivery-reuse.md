# Ускорение малых изменений без повторной работы

Результат: действительные результаты проверок и review переживают сессию; выпуск подтверждается наблюдаемой версией.
Пути: verification_tiers → impact_check_cli/check-fast; evidence_collector → Tool Broker; review_branch; deploy_readiness → запись поставки и локальная блокировка среды.
Инварианты: обязательный CI независим от локального evidence; неизвестные входы запрещают reuse; SKIP ≠ PASS; writer ≠ judge; запреты доступа сохраняются.
Failure modes: устаревший/неполный receipt; пропущенный обязательный тест при ready_for_review; параллельный deploy; сбой с неопределённым исходом; exit 0 при неверной публичной версии.
Доказательство positive: повторные вызовы реально сокращают число исполнений при совпадении входов.
Доказательство fail-closed: изменения входов, отсутствующее evidence, запрет, публичный FAIL/BLOCKED не дают успеха.
Доказательство side-effect: реальные subprocess и конкурентные процессы с файловым следом; освобождение OS-lock после смерти держателя без удаления чужого замка.
Не входит: изменение дочерних репозиториев, branch protection, доступов; удалённый distributed lock; автоматический rollback; заявление о состоянии конкретного опубликованного релиза.
