# #1434 — кому передано ревью при отсутствии свидетельств хоста

Установленный Кит в одноразовой копии на `f81d8f5f` вернул три готовых задания (`evidence`, `ai_eval`, `acceptance`). При этом первым действием было получение отсутствующей квитанции другой модели. Повторный `finalize` создал новую попытку и выдал тот же набор заданий. На `6892fb62` этот маршрут воспроизводится по коду.

**Инвариант.** Штатная выдача поручает обычные готовые задания текущей среде исполнения. Для специализированного результата она называет владельца внешнего свидетельства и условие возобновления. Повтор при прежних входах и отсутствии модельного свидетельства возвращает ту же проверенную ожидающую попытку. Получение новых независимых входов возвращает задачу в штатную проверку.

**Пути.** Проверяются выдача и повтор `project_session finalize`, восстановление сохранённой передачи, путь независимого человека и установленная инструкция. Решение о приёмке по-прежнему принимает штатная проверка свидетельств.

**Регрессии.** Смешанная очередь с обычными задачами, отсутствие свидетельства хоста, повтор без нового работника, новая независимая квитанция или смена входов. Проверки работают в локальном репозитории с нейтральными данными.

Независимое ревью выявило два порядка доставки. Если известный digest пришёл раньше заключения, возобновление ждёт файл с соответствующими байтами. При продолжении без аргументов после отклонённого человеческого digest модельное заключение проходит существующую полную проверку. Явная передача человеческого digest выбирает человеческий путь.
