# Change Brief — #1406: флот и репетиция обновления

**Результат.** `ai-ops products` показывает версию, наблюдаемое использование возможностей и дрейф по каждой выбранной дочке. До создания тега обязательна репетиция обновления на двух закреплённых публичных продуктовых репозиториях.

**Пути.** Реестр продуктов → read-only проверка установленной копии и локальных отчётов → существующий свод и CLI. Релизный SHA → закреплённые Git-снимки → штатные assess/diff/update/validate → реальная проба отрицательного smoke → проверка восстановления байтов, режима файлов и локального Git config → release gate. Используем актуатор и rollback из #1486.

**Инварианты.** Режим репетиции работает только в одноразовых копиях; pin обязателен; нельзя считать skip/нет изменений успешным переходом. Нет записи в исходные дочки, моделей, платных сервисов и публикации частного содержимого. Неизвестные данные помечаются явно. Ошибка кейса останавливает выпуск; точный SHA и старые проверки сохраняются.

**Отказы.** Версии расходятся; пропуск или дрейф до применения; скачался другой снимок; обновление/проверка не прошли; отрицательный smoke не застал новых байтов либо не восстановлены настройки и файлы.

**Доказательство.** Положительный и отрицательный проходы на двух реальных публичных снимках; отпечатки состояния до/после и свидетель изменения до отказа; тесты свода, отказов и привязки release job; независимый review и CI точного head.

**Не входит.** Реальный rollout, изменение формата конфигурации дочки, обновление релизной версии, новый актуатор и правки трёх файлов #1539.

**Полевое уточнение.** На закреплённом снимке dashboard-kit штатный снимок отверг локальный псевдоним навыка. Сохраняем при обновлении и откате прямую ссылку на каталог внутри репозитория, если имя навыка не принадлежит киту. Ссылки в областях записи, под именами поставляемых навыков и за пределы репозитория по-прежнему останавливают обновление до записи.
