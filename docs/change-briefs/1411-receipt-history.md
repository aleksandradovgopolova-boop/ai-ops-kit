- Пути: kit_observability --workitem → workitem_trace → features/<wid>/work-packages/<pid>/{report.json,attempts/attempt-N/report.json}; только существующий reader/CLI, отдельный commit поверх неизменного 404f7a83.
- Источники: workpackage_executor._persist_package_report/retry_package сохраняют/переносят отчёты; pipeline_stages._build_loop_section сохраняет первые ≤40 элементов метаданных loop.transcript; usage_ledger.FIELDS уже содержит package_id, но обычный producer его не штампует: без явно записанного значения корреляция invocation с пакетом unknown. run-history/run-*.yaml содержит настройки, не историю результатов; branch-review/review-verdict перезаписываются. Native thread/turn не сохраняются normalize ledger.
- Инварианты: без новой instrumentation/hooks/capture/export/network/runtime/model calls; не читать реальные transcripts при разработке; только fixtures. Выход — псевдонимы id и разрешённые скаляры, без reason/task/transcript prose/команд/путей/содержимого инструментов.
- Failure modes: чужой WorkItem или тип report; symlink/повреждённый/неполный архив; numeric attempt-2/attempt-10 порядок; повтор snapshot/step против реального повторного действия; ложная корреляция package storage attempt с Run/Invocation.
- Доказательство: positive fixture из настоящего producer формы отчёта, archive+current+ledger+package_end; fail-closed corrupt/mismatched/symlink/duplicate steps; side-effect proof реальные файлы до snapshot и запрет write/network/subprocess при чтении. Целевые регрессии, core smoke, ruff/layering/docs, независимый read-only review.
- Граница: архивное attempt-N — номер хранения retry пакета, НЕ attempt_id глобального прогона; текущему snapshot номер попытки не присваивается. package_id связывает observations, но не доказывает, какой invocation вызвал tool/gate/review. Метаданные tool-loop усечены producer до40 и включают denied/proposed действия, поэтому показываем tool_attempt, не полные фактические tool_calls. Между источниками/пакетами причинного времени не выводим; отсутствующее unknown. Общие метрики истории не пересчитываем из повторяющихся snapshot.
