# Strict mypy на независимом срезе контрактов — #1412

Результат: штатный `mypy` проверяет в strict-режиме порты ядра, общие TypedDict,
шину событий и существующий RunContext. Ратчет запрещает сокращение этого охвата.
Затрагиваемые пути: `pyproject.toml` → существующий CI-шаг mypy; `kernel/ports.py`,
`shared/contracts.py`, `shared/events.py`, `engine/run_context.py` → их реальные потребители.
Инварианты: JSON Schema остаётся источником внешних форматов; stdlib + PyYAML;
состояние прогона остаётся в RunContext; поведение фабрики и событий не меняется.
Failure modes: забытый target; выключенный strict-флаг; широкое подавление ошибок;
потеря типов при импорте; изменение runtime-поведения при аннотировании.
Доказательство: конфигурационный ратчет, положительные/отрицательные mypy-пробы
на настоящих импортированных контрактах, существующие тесты фабрики/портов/событий,
core smoke и Ruff; широкий профиль — через общий host-slot.
Не входит: полный strict всего пакета, роутер, runtime adapters (#1434), py.typed,
новый runtime-валидатор или внедрение Pydantic. #1412 остаётся открыта для следующих срезов.
