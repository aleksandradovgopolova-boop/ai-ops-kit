# #1408 — импорты JS/TS по синтаксическому дереву в проверке слоёв дочки

Составлен по ходу реализации, а не до неё — отступление от инженерного цикла названо здесь, а не скрыто.

Результат: проверка слоёв дочки (`architecture_invariants`) по объявлению `parser: tree-sitter` читает импорты JS/TS синтаксическим деревом и видит многострочные и динамические импорты, которые построчный regex пропускал; импорт из комментария или строки ребром больше не считается. Замер полноты и времени на двух открытых репозиториях.

Затрагиваемые пути: объявление `architecture-invariants.yaml` / `.ai-ops.yaml standard.architecture` → `report()` → `analyze_import_graph` → `context.js_imports.AstImportReader` (ленивый импорт опционального пакета) или прежний regex → рёбра зон → `check()` → блок `architecture` отчёта governance → `governance_report.render`.

Инварианты: способ по умолчанию и его вывод не меняются; default не импортирует tree-sitter; tree-sitter не становится обязательной зависимостью; файл, не разобранный деревом, читается прежним способом, и причина видна в отчёте; частично восстановленное дерево успехом не считается; слои пакетов (`planning` → `context`) без цикла.

Основные failure modes: нет пакета — проверка молча пустая; синтаксическая ошибка даёт частичный список импортов; литерал с escape теряется без следа; неизвестное значение `parser` роняет отчёт; тесты дерева всегда пропускаются в CI, потому что грамматика не установлена.

Доказательство: positive — дерево находит многострочный и динамический импорт, ре-экспорт, TS `import = require`, шаблонную строку без подстановок; fail-closed — без пакета, на синтаксической ошибке, `.vue` и escape файл уходит в regex с причиной, без пакета default не импортирует tree-sitter, под `AI_OPS_JSTS_AST=1` отсутствие грамматики — провал, а не skip; side-effect — на одном и том же дереве дочки regex пропускает межзонное ребро, а дерево его находит и отбрасывает ложные. Замер — `devtools.jsts_import_compare` на закреплённых коммитах. Независимое read-only review всей delta.

Не входит: перевод `context/repo_graph.py` на дерево, разрешение алиасов/tsconfig paths/`exports`, `.vue`/`.svelte`, повышение инварианта выше `advisory`, смена способа по умолчанию.
