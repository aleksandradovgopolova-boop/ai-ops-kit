# Пульт продукта на одном экране

## Результат

Владелец видит на одном экране здоровье, метрики, фокус, роадмап, выпуск и артефакты. Каждая карточка артефакта открывает содержание и ссылку на первоисточник. В бэклоге цели и ожидаемые решения описаны по-русски.

## Пути

Обзор и диалоги используют опубликованные данные и встроенный снимок. Полные списки, состав выпуска, сведения стратегии и разделы паспорта доступны в диалогах. Опубликованный выпуск показывает текст одноимённого GitHub Release. Предстоящий выпуск показывает входящие изменения по подтверждённым источникам, известные ограничения и оставшиеся шаги. Названия целей берутся из плана. Отсутствие данных обозначается явно.

## Проверка

В настоящем браузере сравниваем высоту и ширину документа с вьюпортом, проверяем границы секций и доступность подвала без прокрутки. Проверяем восемь карточек, ссылку, Escape и возврат фокуса. Длинный роадмап, длинный состав и отсутствие части данных проверяются отдельно. Счётчики и источники качества сохраняют прежнее значение.
