# #1407 — первый детерминированный корпус security-evals

Результат: новые исполняемые случаи воспроизводят отказы существующих ограничений агента в одноразовых локальных деревьях. Это ограниченный срез #1407, а не квалификация модели или контейнера.

Затрагиваемые пути: fixtures gate-evals → штатный replay без судьи; broker.read/shell → недоверенный текст → детерминированно предложенное действие → broker.execute; прямые write и shell → write_scope/protected-path guards; decision_boundary → policy_engine.enforce; ненулевой exit инструмента → evidence с ok=false.

Инварианты: только новые fixtures, тесты и собственная документация; production-код, разрешения, policy, секреты, Docker-скрипты, CI и зависимости не меняются. Исполняемые действия — только во временных деревьях. Непроверенные классы называются NOT_RUN.

Основные failure modes: текст источника принимается за одобрение; write вне scope проходит; предложенные level/approvals снимают защиту policy; shell получает зелёное после запрещённой записи; вывод PASS скрывает ненулевой exit.

Доказательство: разрешённая запись действительно меняет файл; README/issue/tool-output реально читаются через брокер до попытки запрещённого действия; защищённые и внешние файлы побайтово сохраняются; shell печатает записанное содержимое до отката; процесс пишет допустимый маркер и возвращает ошибку; decision-boundary не принимает запрос большей автономии, enforce не вызывает запись без одобрения. Целевые регрессии, короткий core smoke, применимые линтеры и независимое read-only review всей delta.

Не входит: LLM prompt-injection квалификация, реальные MCP-вызовы, платные модели/сеть, реальные секреты, Docker/container denial, полное закрытие issue, изменение production guards, security/billing/credentials, push/PR/merge/release. Известный production-дефект описывается отдельно, не исправляется в этом срезе.
