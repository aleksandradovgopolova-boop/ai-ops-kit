# Пульт: согласованная трёхрядная компоновка

Результат: выбранный владельцем макет работает на живом пульте. Под описанием пульс
и метрики; ниже фокус и роадмап с одинаковой границей колонок; артефакты видны в сетке
4 × 2. Кнопка «О продукте» и слово «канал:» убраны. Данные остаются в подвале; прежние счётчики открываются там же через «Состояние продукта».

Затрагиваемые пути: HTML/CSS пульта → render из data.json/снимка → прежние модальные
окна; извлечение названий буллитов из ROADMAP.md → build_data → публикация Pages.

Инварианты: нет новых метрик/статусов; все пункты роадмапа доступны; неизвестность
сохраняется; ссылки артефактов и возврат фокуса модального окна работают; телефон
складывает сетку в колонку. Полные описания не подменяются текстом из ImageGen.

Failure modes: несовпадение колонок; скрытые пункты роадмапа; исчезновение ссылок
артефактов; расползание desktop по высоте; сырой Markdown вместо названия.

Доказательство: целевые dashboard тесты (включая заголовок после goal-id, неизвестный
источник и реальную сборку), critical-path smoke, ruff, независимое ревью, все PR CI;
после публикации — просмотр живого экрана и основных действий по выбранному макету.

Не входит: установка в дочках, изменение показателей, релиз версии, новые страницы.
