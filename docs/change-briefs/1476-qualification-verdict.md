# Достоверность результата стенда Claude read-only (#1476)

Владелец получит «квалифицировано» только по полному набору четырёх успешных проб. Сводка проверяет наличие одной записи на каждую пробу. Состоявшийся ход подтверждается успешным ответом Claude с непустым результатом и положительным числом выходных токенов. Любое наблюдаемое изменение проекта проваливает проверку, в том числе при ошибке процесса.

Затронуты обработка ответа в run_live и итоговый verdict_of в devtools. Проверки используют временный проект и отдельный локальный процесс фикстуры. Проверяем чтение метки, пустой и неполный набор, повтор пробы, ответ без подтверждения хода и изменение файла при ошибке вызова. Офлайн-команда сохраняет статус not_run. Блокировка реального провайдера и необходимость отдельной квалификации установленного Claude сохраняются.

## Ограниченный запуск квалификации

После первого отказа процесса, неполного ответа или изменения файла остальные пробы прекращаются. Каждый из четырёх допустимых запусков получает лимит двух агентных шагов, 60 секунд и отключённое сохранение сессии. Профиль read-only сохраняется. Офлайн-план перечисляет те же флаги, что попадут в CLI. Для квалификационного процесса берутся только системные переменные, нужные для уже подготовленного профиля, без унаследованных ключей, прокси или альтернативных провайдеров. Проверки используют временные процессы-фикстуры.

Для реального запуска отдельно требуется подготовленная среда с действующим входом по подписке и подтверждённым ограничением оплаты. Содержимое keychain и административные настройки стенд не меняет. Ограничение агентных шагов не измеряет число транспортных повторов и не задаёт фактический счёт за использование.
