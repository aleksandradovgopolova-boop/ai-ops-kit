# #1446 — версия Кита и PR обновления в выбранных проектах

Владелец запускает частный отчёт для явно названных репозиториев. Для каждого
проекта отчёт показывает версию в основной ветке, коммит наблюдения и
подтверждённый PR перехода версии, когда GitHub позволяет установить связь.
Публичный план содержит только ссылку на инструкцию, частные данные остаются у владельца.
Путь чтения проходит через режим родительского release tooling и GitHubClient.

Версию подтверждают согласованные файлы конфигурации и managed/VERSION на
фиксированном SHA. Для PR проверяются переход относительно первого родителя,
принадлежность основной ветке, merge SHA и серверный статус слияния. Перед
выводом сверяются имя и вершина основной ветки. Отказ чтения, повреждённый
объект, неоднозначный PR, отсутствие изменения версии или движение ветки
оставляют соответствующий результат неизвестным.

Проверки воспроизводят переход версии, частичное наблюдение и подмену связи
с PR. Тест CLI проверяет запросы и отсутствие записи в проект. Pages, выпуск,
production и восстановление имеют собственные источники. В этой работе
владелец получает результат через локальный stdout.
