# Где прервался сбор состава выпуска

24 ноября публикация 45347371448 подтвердила 29 изменений на 33f77716. Запуски 45348772519 и 45350550270 на том же коммите показали только этап pull_links_and_ci и общий отказ GitHub. Операцию и причину сетевого сбоя установить по этим снимкам нельзя.

В случае ошибки чтения пульт должен называть операцию: связь коммита с PR, карточка PR, чтение списка запусков или задач попытки, проверка связей head после слияния. Для нужной операции допустимы проверенные SHA коммита, номер PR, имя известного workflow, номер запуска и попытка. URL, тексты исключений и тела ответов в публичную проекцию не входят. Неуспешное чтение оставляет состав и готовность неподтверждёнными. На успешном пути число запросов и итоговый план сохраняются.

Проверка использует штатные capture и build на временном Git-репозитории с выборочным отказом транспорта. Тесты сверяют вызванную операцию, отсутствие лишних запросов и отсутствие внешнего текста в снимке.
