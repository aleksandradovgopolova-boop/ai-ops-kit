# Удаление оставшихся очевидных повторов перед выпуском

21.10.2026. Поручение владельца: проверить пробелы в ускорении Kit и дочерних процессов до
следующего выпуска. База — main после #1358. Пульт, ИИ-Среда и ЖКХ вне этой работы.

**Что.** Отменять устаревшие PR-прогоны трёх проверочных workflows Kit; не строить граф кода,
если текстовый поиск не вернул Python-кандидатов; читать и разбирать исходник один раз при
построении одного графа. Уточнить команды verify/regression/finish, чтобы переход между ними
не означал повтор тех же команд. Сохранить отдельный отчёт о незакрытых границах ускорения.

**Зачем.** Старый SHA занимает раннер после нового push; поиск документов запускает ненужный
обход исходников; граф повторно читает каждый файл и повторно разбирает Python AST.

**Границы.** Состав required checks и условия merge/release прежние. Push/main, ручные и
разные PR не отменяют друг друга. Кеша графа между вызовами нет: новые файлы и изменения
читаются заново. Access-filter и full-fallback не ослабляются. Новых механизмов receipts,
host-lock или автоматического доверия окружению дочек нет.

**Проверяемо.** Существующие тесты графа и контекста; счётчик реальных чтений/AST вместо
сравнительных замеров; регрессия запрета чтения denied-файлов; проверка групп отмены workflows.
Только целевые локальные тесты, затем один штатный CI. Один независимый review до merge.

Результаты и незакрытые границы: [ревизия ускорения](../pre-release-speed-audit-20261021.md).

**Находка review до дополнительной правки.** Дочерний pipeline передаёт подбору только
последний коммит. При нескольких коммитах writer ранняя правка выпадает из draft-выборки.
Исправление: полный диапазон base_sha..committed_sha; неизвестная база/ошибка git дают None
(полный профиль), а не пустой список (skip). Проверка — два реальных коммита, ранняя регрессия
и поздняя проза, через производственный сбор evidence; неизвестная база сохраняет полный набор.
