# Командное подключение кита — #1434

Границы срезов и статус приёмки: [проектное подключение команды](../agent-guides/team-session-integration.md).

Результат первого среза (эксперимент, `standard.team_session: required`): общий
проектный вход Claude Code/Codex, диагностика текущего checkout и
проверка фактического исполнения вместо доверия тексту «кит использован».

Затрагиваемые пути: init/update → ограниченные блоки AGENTS.md/CLAUDE.md и проектные
hooks → старт/продолжение/compact → постановка → штатный pipeline → проверка завершения;
doctor/CI проверяют доставленную конфигурацию. Учёт остаётся в `.ai/runtime/sessions/`.

Инварианты: не менять разрешения, доверие runtime, credentials и личные настройки;
сохранять собственные инструкции и хуки проекта; пути вычислять по фактическому cwd;
одна политика для обоих runtime; planning/mock/чужое/протухшее evidence не равно исполнению.

Failure modes: отключённый hook; смена checkout/ветки/политики; чужая задача/сессия;
план без запуска либо ошибка; повреждённые настройки/артефакты и выход симлинка за корень.

Доказательство: positive — штатный процесс пишет результат и проверяемое подтверждение;
fail-closed — отсутствие/изменение/подмена не дают принятого исхода; side-effect proof —
перед отрицательным verdict доказать наличие созданных файлов и фактическое изменение Git/FS.
Чистый clone с отдельным HOME проверяется автоматически; это не два аккаунта коллег.

Не входит: исследование самой ИИ-среды, продуктовый код, новые платные вызовы без бюджета,
автоматическое доверие хукам, объявление всех app/cloud режимов поддерживаемыми.
Живая приёмка независимых участников и доставка в ИИ-среду обязательны до закрытия issue;
запись в её checkout — после согласованного окна с владельцем активного релиза.
