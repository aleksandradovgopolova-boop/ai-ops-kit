# #1434 — сохранённая задача при потере указателя сессии

В изолированном проекте после потери части файлов запись подготовленной задачи сохранилась, а указатель active.json исчез. Новый ввод должен остановиться до создания другой задачи. Восстановление работоспособности рабочей копии остаётся у её владельца.

Проверяем оба штатных входа и SessionStart, а также различие между новой сессией и сессией с сохранившимися следами исполнения. При неполных данных проверяем причину отказа и побайтовую сохранность постановки, квитанций и claim. Чтение выполняется под существующим ограничением времени hook. Изменение не восстанавливает указатель, не запускает задачу и не меняет правила её приёмки.
