# Change Brief — публичный код недоступного исполнителя (#1483)

**Результат.** Публичная декларация описывает существующий код CLI 3; лимит
модели и недоступная среда подтверждены через консольную процессную границу.

**Затрагиваемые пути.** docs/api/public-surface.md → контракт кодов;
tests/contracts/test_public_surface.py → main, _main_guarded и console entry;
newsfragments → пояснение владельцу; docs/change-briefs/README.md → достижимый
из общего индекса бриф. Runtime-код не меняется.

**Инварианты.** Смысл 0/1/2 и фактический rc3 сохранены; причина в stderr,
неожиданный дефект не маскируется. Ни модель, ни реальный проект не запускаются.

**Failure modes.** Необъявленный guard-код; пропущенный guard консольного входа;
traceback вместо типизированной причины; ошибочный catch-all; повтор/запись в проект.

**Доказательство.** Новый AST охватывает guard. Positive — два типизированных
отказа дают rc3 с человеческой причиной. Fail-closed — обычный RuntimeError
остаётся видимым дефектом. Side-effect proof — marker фиксирует один фактический
вызов main с корректным cwd до оценки returncode; дерево fixture неизменно.
Для 0/1/2 есть отдельные process cases. До добавления rc3 в декларацию получены
три ожидаемых отказа (AST и оба process cases), журнал /tmp/1483-before-20261117.log.

**Не входит.** Изменение runtime, providers, trust/security/settings, зависимости,
публикация/merge, выпуск, live-модели, доставка/приёмка #1434.

**Порядок работы.** Бриф записан после первого запуска новых регрессий; это
отступление от требования «Change Brief до кода», а не соблюдённый шаг. Охват,
инварианты и наблюдаемый red сохранены явно для независимой проверки.
