# #1446 — подготовленная ветка обновления в списке дочерних проектов

Оператор видит в `ai-ops products`, для какого проекта установщик подготовил локальную ветку обновления и на каком коммите. Источники — последний локальный отчёт штатного update и Git выбранного проекта. Сведения остаются в частном реестре оператора.

Установщик записывает коммит обновления и его единственного родителя после успешного создания коммита. При чтении сверяем текущую базу, локальную ветку, версию в её дереве и согласованность установленной версии. Старый отчёт, подмена версии, смена ветки обновления или продвижение базы оставляют статус неизвестным. Номер удалённого PR, установку и откат подтверждают отдельно.

Проверки охватывают реальный installer update в тестовом Git-проекте, чтение отчёта после повторного открытия, неполный отчёт, расхождения Git и отсутствие записей при просмотре. Схема плана выпуска, публичный пульт и порядок установки сохраняются.
