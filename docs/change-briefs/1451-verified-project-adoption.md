# Change Brief — #1451: подтверждённое использование Kit

**Результат.** `reach adoption report` показывает зарегистрированные, подтверждённо установленные, активные и обновлённые проекты раздельно. Рядом видны источник, дата, окно, охват и причина неизвестности. Действующий receipt exchange сохраняется; внешнее самосообщение не становится проверенным.

**Пути.** Явно выбранные локальные checkout с действующим согласием → существующие проверки UUID/целостности → отдельная локальная квитанция независимой проверки владельца сводки, закреплённая SHA256 → сверка Git и managed-инвентаря → тот же report/CLI. Импорт и tombstone влияют на отсев отозванных согласий. Локальный отзыв хранит терминальную отметку по consent_id после повторного согласия; чтение сводки ничего не меняет.

**Инварианты.** Отдельный доверенный вход подтверждает происхождение инвентаря, независимость продукта и факт продуктовой работы, а код проверяет его привязку к реальным байтам и истории. Hash сам по себе не аутентифицирует автора. Источник даты — закреплённый коммит, не дата импорта. UUID дедуплицирует клоны; конфликт — неизвестно. Parent и подтверждённые fixtures отдельно. Внешний точный total неизвестен.

**Отказы.** Самосообщение вместо независимой проверки; синтетический или неточный инвентарь; старое/чужое событие и неверный переход версий; конфликт идентичности/принадлежности и отзыв; утечка путей/сеть/запись при чтении.

**Доказательство.** Реальные Git-коммиты и сверенный инвентарь в синтетических репозиториях; независимая product-аттестация, проверка before/after, окна и replay; сломанные доказательства закрывают подтверждение; до/после сверить файлы и блокировку сети. Проверить публичный CLI и совместимость прежней сводки. Независимое ревью и CI точного head.

**Не входит.** Сервер, отправка, платные вызовы, изменение дочерних проектов/релиза/плана, новый контур аналитики. Файлы PR #1539 не меняем.
