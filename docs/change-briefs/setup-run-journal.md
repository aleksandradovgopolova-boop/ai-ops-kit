# Запуск установки с общим бюджетом и сохраняемым журналом

Результат: установка укладывает подпроцессы в единый бюджет (150 секунд по умолчанию), при остановке сохраняет уже полученный вывод и называет шаг и путь журнала. Новая попытка не стирает предыдущую.
Затрагиваемые пути: installer CLI → setup → init/doctor/onboard/bootstrap/model → фиксация только файлов установки; локальные журналы → gitignore; CLI-справка и публичная документация; тесты установщика.
Инварианты: stdlib + pyyaml; продуктовые файлы и чужой индекс не меняются; журнал не коммитится; неуспешная/прерванная установка не становится успешной; старые способы вызова сохраняются; стоимость и время человека неизвестны, а не нулевые.
Failure modes: превышение общего бюджета; потеря частичного stdout/stderr; оставшийся дочерний процесс; неполная установка после прерывания; затёртый журнал при повторе.
Доказательство: реальный подпроцесс пишет маркер до зависания — после timeout маркер и вывод остаются, дальнейшее действие отсутствует; общий бюджет уменьшается между шагами; успешный setup даёт упорядоченный журнал и не включает его в коммит; отдельный smoke на macOS и тест с чистой Git-конфигурацией; свежий независимый review и full-current-python перед коммитом.
Не входит: ускорение анализа репозитория без профиля задержки, новый режим маленьких задач, автоматическая приёмка человеком, ретроактивная регистрация квалификационного прогона, публикация новой версии.
