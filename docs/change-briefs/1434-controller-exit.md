# #1434 — сохранить причину отказа контроллера до чтения отчёта

Открытая сессия готовит спецификацию и запускает контроллер. Если процесс завершился с ошибкой, оператору нужны его код выхода и путь к журналам. При отказе записи общего реестра вторичная ошибка чтения отсутствующего отчёта скрывала этот исход.

Затронуты подготовка текущей сессии и восстановление передачи. Известный ненулевой код сохраняется вместе с попыткой и исключает принятие внешне корректного файла отчёта при восстановлении. Для прерывания с неизвестным исходом и для прежних записей сохраняется существующая проверка доказательств.

Проверяем обычную подготовку, завершение процесса с ошибкой без отчёта и с уже записанным корректным отчётом. После восстановления проверяем неизменность заявки, состояния и единственное исполнение. Полные stdout и stderr остаются в локальных журналах. Размещение общего реестра, полномочия процесса и приёмка продукта в этот срез не входят.
