Каталог фич продукта теперь собирается сам в контуре дочки. Доставляемый child-CI workflow на push в
main регенерирует `docs/feature-catalog.md` из реестра фич дочки и коммитит обновление, а на PR
сверяет его без коммита — так системный аналитик получает единый читаемый список всех фич продукта
автоматически, а не собирает картину по коду и тикетам. Генерация зовёт уже поставляемый рендер
каталога из клона кита, поэтому новых доставляемых модулей не добавляет; у продукта без реестра фич
workflow честно ничего не генерирует, а не падает.
