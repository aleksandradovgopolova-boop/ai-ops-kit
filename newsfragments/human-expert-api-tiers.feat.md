Поверхность из 32 интентов разделена на два явных уровня аудитории, ортогонально совместимости (`docs/api/public-surface.md → audience`): **human** — повседневная поверхность владельца, ровно «интерфейс 4+1» из `marketplace.json` (`status / inbox / next / explain / do (+ run / model / review)`), и **expert** — специализированное/advanced (specify/plan/governance/replan/backlog/graph и т.д.). Контракт-тест держит человеческий набор малым (≤ 10), сверяет его с объявлением плагина (одна правда, не две) и требует, чтобы каждый интент имел ровно один уровень аудитории. Ни одна команда не удалена и не переименована — названа только адресация, чтобы внутренний движок не торчал наружу (ревью §12, issue #632).
