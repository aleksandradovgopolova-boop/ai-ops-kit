Доставка называет в теле PR, как прогон обошёлся со статус-доками репозитория: либо статус-док обновлён этой доставкой, либо явно указана причина-исключение (управляемого статус-дока нет / это шаблон / нет разметки свежести). Так сгенерированный PR не упирается молча в собственный гейт свежести — у ревьюера есть честный след (#404).
