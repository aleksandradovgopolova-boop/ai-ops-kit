Ратчет test-taxonomy больше не форсит ре-снап baseline на каждое изменение состава тестов (#680): снято точное равенство `baseline == замер` (`test_baseline_matches_the_measurement`), которое краснело даже когда доля поведенческих не падала (14 ре-базлайнов за один день 08.09). Реальная защита сохранена — НИЖНЯЯ граница доли: `check()` в валидаторе (перекрёстное умножение) + `test_current_share_meets_baseline` (замер кита не ниже baseline, значит baseline не завышен) + проба покраснения `test_share_drop_reddens`. Baseline теперь — пол доли, обновляемый записью в `raises` только когда доля законно падает.
