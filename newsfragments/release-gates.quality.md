Выпуск проверяется механизмом, а не памятью: в ветке обязана появиться запись для CHANGELOG
(`towncrier check`), новые коммиты обязаны быть conventional (`cz check` от точки включения), а
релиз без раздела CHANGELOG для своей версии больше не выходит с краткими записками — он отказывается.

Ворота выпуска исправлены по находкам собственного CI: разбор конфига больше не требует Python 3.11
(пол репозитория 3.9), и у механизма выпуска появилась проба шва — прежде отключение вызова не
поймал бы ни один тест.
