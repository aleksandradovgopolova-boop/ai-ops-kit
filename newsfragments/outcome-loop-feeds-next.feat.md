После релиза петля доходит до КОНКРЕТНОГО следующего действия, и оно появляется в `next` с обоснованием «потому что <что произошло с продуктом>» (метрика взяла/не взяла цель, гипотеза подтвердилась или нет) — так замыкается idea → decision → build → release → measure → learn → next decision; без измеренного итога `next` ничего из петли не добавляет.
