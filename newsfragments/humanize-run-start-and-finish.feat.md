Старт и финиш прогона на product-аудитории — человеку, а не координационной телеметрией: вместо
внутренних идентификаторов (`ACTIVE-WORK 'wi-…'`, сессия, машина, ветка, строка `WORKTREE`) кит
говорит «начал работу в отдельной копии проекта — main не трогаю», а при остановке называет
причину без жаргона. На `technical`/`debug` полная форма с id сохранена; пересечения параллельных
сессий и факт публикации заявки наружу видны на любой аудитории (#708).
