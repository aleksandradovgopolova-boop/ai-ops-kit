Все 128 монолитных `*_selftest.py` сольного покрытия переведены в гранулярные `test_<имя>.py` — каждое поведение стало отдельным именованным тестом с настоящим assert. Суффикс `_selftest` уходит из конвенции.

**Что изменилось:**
- ~140 файлов мигрировано (128 монолитов + 12 из предыдущей прополки)
- Каждый `expect()` внутри монолита → отдельный `test_*` метод
- Все тесты помечены `@pytest.mark.unit` (читается ярусами)
- Файлы переименованы: `test_foo_selftest.py` → `test_foo.py`
- Для валидаторов: `test_validate_*_selftest.py` → `test_validate_*.py`

**Почему:** Монолитные selftest (одна мега-функция на файл, десятки проверок через воронку в один `assert ok`) имели низкую диагностическую ценность — один красный на весь модуль. Гранулярные тесты показывают ЧТО именно сломалось.

**Чек покрытия:** ни одно поведение из монолита не потеряно — каждый `expect()` перенесён. Число тест-функций выросло как следствие.
