Введён `RunContext` (`ai_ops_kit/engine/run_context.py`) — мутабельный объект переписываемого состояния pipeline-прогона `run()` — и через него из `run()` вынесен первый из оставшихся крупных блоков: восстановление policy/классификации при resume (`_restore_resume_policy`). Поведение сохранено (restore из run-settings, fail-closed на битом файле, immutable drift-отказ, F-027 продуктовая задача); func-size ратчет `run()` опущен 812 → 750. Это скелет для последующего выноса остальных блоков `run()` (model-routing, execute+fix-loop, delivery), которые переписывают до десятка локалов и потому не выносятся без объекта состояния.
