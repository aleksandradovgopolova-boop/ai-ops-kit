Извлечение поверхностей продукта теперь видит операции gRPC: из `.proto`-контрактов кит вычитывает
объявления `rpc` внутри блоков `service` (включая потоковые `stream`) и заносит их в каталог как
операции API — второй носитель вида `api` рядом с GraphQL. Разбор текстовый, без запуска protoc,
поэтому уверенность честно помечается «предположительно» (не блокирует прогон); модели данных
(`message`/`enum`), сгенерированные stubs, reflection и REST-mapping через `google.api.http` осознанно
не берутся.
