Появился явный opt-in `ai-ops run --parallel`: неатомарную задачу можно исполнить по-настоящему
конкурентно — каждый пакет в своём одноразовом клоне репозитория и ветке, со сборкой результата
(fan-in) и повторной проверкой на свежей интеграционной ревизии. По умолчанию флаг выключен, и
поведение обычного прогона не меняется; атомарная задача автоматически откатывается в обычный
прогон. Основной рабочий каталог при этом не трогается — вся работа идёт на клонах.
