Описание задачи (`specify`) больше не показывает человеку внутренний id фичи (`wi-…`) и флаги CLI (`--feature`, синтаксис `--answers`). Вход — одна фраза; в ответе кит эхом повторяет, что понял («Поняла: «…».»), задаёт недостающее обычными словами и ведёт к плану продуктовым языком, а точные команды остаются в технических деталях по запросу (#958).
