Теперь можно записать подтверждённую расписку о поставке для PR, который вы влили руками: `ai-ops delivery record <фича> --pr <номер|url>`. Кит сам спрашивает GitHub, действительно ли этот PR влит, и только при подтверждённом слиянии записывает расписку — так честно доставленная фича перестаёт собирать ложные требования «докажи поставку». Если GitHub говорит, что PR не влит (открыт или закрыт без слияния), или спросить нечем (нет токена/доступа), кит расписку не пишет и говорит об этом прямо — доказательство поставки не выдумывается.
