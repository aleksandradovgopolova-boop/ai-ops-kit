Две работы про «измерять против итога слияния» и «дрейф-безопасную доставку» переформулированы фордж-нейтрально: инвариант держит сам кит (merge-preview через git merge-tree + ре-верификация зелёного PR против текущей цели перед слиянием), а не нативная GitHub merge queue. Причина — merge queue недоступна для личных репо и в принципе привязывает кит к одному форджу и типу репозитория, что противоречит его абстракции runtime/провайдеров. Статус вернулся из waiting_on_owner в todo (фордж-нейтральный механизм ещё не построен).
