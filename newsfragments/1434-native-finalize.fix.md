Завершение native-сессии учитывает явно отключённый OpenSpec: проверяет настоящую
Spec-First спецификацию отдельным профилем, сохраняя обязательный gate и прежний
strict CLI по умолчанию. Специализированный red team получает отдельное
человеческое задание с привязкой к ревизии и артефактам; это fallback, а не
замена предусмотренной политикой независимой другой модели. Security parser
не принимает один shell:false за доказательство безопасности других shell options.
Неподтверждённые SQL/long-launch exemptions отозваны; такие findings остаются blocking.
