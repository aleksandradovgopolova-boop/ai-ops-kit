Описание выпуска кита теперь начинается с сообщения человеку, а не с инженерного журнала (#1210). Выпуск собирается только с описанием для владельца по шаблону (что меняется для вас, что вошло, известные ограничения, что сделать после выпуска); известные ограничения из новых фрагментов `*.limit.md` бамп дописывает сам, и слой строго проверяется правилами описания выпуска — при сборке и ещё раз перед созданием выпуска. GitHub Release показывает именно этот слой, а не весь раздел со «Служебным»; PR обновления дочки выводит слой каждой версии между прежней и новой текстом, а не внутри JSON. У выпусков, собранных раньше, слоя нет — там по-прежнему показан заголовок раздела, и это сказано прямо.
