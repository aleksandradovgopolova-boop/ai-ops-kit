Описание выпуска кита теперь начинается с сообщения человеку, а не с инженерного журнала (#1210). Выпуск собирается только с абзацем «что меняется для вас»; в начало раздела CHANGELOG ложится короткий слой владельца — этот абзац, «Известные ограничения» (из новых фрагментов `*.limit.md`, явное «Нет», если их нет), «что дальше» и ссылка на полный список. GitHub Release показывает именно этот слой, а не весь раздел со «Служебным»; PR обновления дочки выводит слой каждой версии между прежней и новой текстом, а не внутри JSON. У выпусков, собранных раньше, слоя нет — там по-прежнему показан заголовок раздела, и это сказано прямо.
