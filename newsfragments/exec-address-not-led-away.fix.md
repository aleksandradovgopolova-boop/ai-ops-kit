Адрес запуска команды больше не уводится мимо настоящей строки. В файле без расширения
(`server/Jenkinsfile`) закомментированный безопасный вызов прежде снимал флаг с импорта
`child_process`, и файл пропадал из отчёта; теперь комментарии в нём гасятся по правилам
JavaScript, а флаг импорта остаётся — язык здесь выбран, а не узнан (кроме файлов со строкой
`#!/usr/bin/env node`). Регулярка с `/*` внутри класса символов в `.jsx/.tsx` больше не прячет
настоящий вызов ниже. Текст, похожий на вызов, внутри строкового литерала вызовом не считается, а
аргументы настоящего вызова по-прежнему читаются. Тесты и конфиги инструментов узнаются по имени
файла в любом регистре (`Payment.Test.ts`, `Vite.config.ts`); каталоги — с регистром, чтобы боевая
страница `src/pages/Test/` не ушла из боевого списка. Раздел поставки кита — только точный
`.ai/managed/`.
