Обновления теперь выбираются из НАЗВАННОГО меню стратегий, а не из двух безымянных режимов. Кит
объявляет в реестре четыре стратегии с описанием каждой — `pr` (дефолт, обновление готовится как PR
на ревью владельца), `manual` (владелец применяет сам), `scheduled-batch` (обновления группируются и
открываются одним PR по расписанию) и `auto-stable` (автоприменение из канала stable). Резолвер
читает выбор владельца, называет его в `doctor`, а неизвестную стратегию честно отвергает, не
подставляя тихий дефолт. `auto-stable` объявлена доступной только на канале stable и только при явном
включении владельцем — это декларация свойства, а не поведение: обновление к репозиторию кит сам не
применяет. Сборка релиза стала осознанной: helper собирает состав по вехе или расписанию, а не
реактивно на каждый мерж.
