Имя `onboard` больше не значит два разных действия. Команда установщика, показывающая зрелость
UI-evidence (Storybook), переименована в `ui-status`: интент движка `onboard` определяет стек
репозитория, и обёртка `./ai-ops onboard` ведёт именно в него — прежнее совпадение имён
противоречило QUICKSTART. Старое имя команды установщика удалено, `./ai-ops ui-status` доступна.
