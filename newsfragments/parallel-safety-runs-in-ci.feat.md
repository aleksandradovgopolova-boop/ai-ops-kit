Проверка параллельной безопасности теперь исполняется в CI — и у кита, и у дочки. Если PR смешивает
обычный код с правкой координационного файла (план, история работ, реестр решений, публичные числа
релиза), проверка краснеет: такой PR делает все остальные открытые PR устаревшими на каждый чужой
мёрж. Чистый PR — только код или только «бухгалтерия одной рукой» — остаётся зелёным. В контуре кита
проверка вынесена отдельной задачей и пока не блокирует слияние жёстко (обкатка non-blocking по
правилу dp-002): красный виден, но перевод в обязательные — отдельное решение. У дочки список
координационных файлов берётся из клона кита, поэтому проверка работает даже на свежей установке,
где своего списка ещё нет.
