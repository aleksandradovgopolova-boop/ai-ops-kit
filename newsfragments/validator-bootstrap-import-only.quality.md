Проверка bootstrap загружает настоящие валидаторы в изолированном процессе без повторного выполнения их рабочих сценариев. Отдельное процессное покрытие main обязательно для каждого файла; ошибки импортов, отсутствие эффекта bootstrap и загрузка чужой копии приводят к отказу. Рабочие сценарии и итоговые проверки сохранены; экономия времени всего цикла пока не измерена.
