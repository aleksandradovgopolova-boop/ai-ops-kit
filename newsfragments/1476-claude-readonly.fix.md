Claude CLI теперь отказывает до запуска, пока read-only ограничения runtime не подтверждены;
прежний `allowedTools` сам по себе не ограничивал доступный набор инструментов. Оба имени
`claude-cli` и `claude-code-local` временно недоступны для живого вызова; причина и следующий шаг —
[в контракте](docs/claude-readonly-contract.md). Офлайн mock и явно выбранные API-провайдеры сохранены.
Writer workflow сохраняет такой отказ как `blocked` с причиной и стадией для продолжения,
сохраняя уже подготовленные артефакты; отказ не превращается в успешную стадию даже при полных гейтах.
