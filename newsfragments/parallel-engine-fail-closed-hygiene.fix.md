Параллельный движок закрыл четыре щели в защите fan-in, каждая — с последствием для честности выпуска.
Финальная rev-привязка aggregate больше не открывалась настежь, когда integration-SHA не передан: раньше
проверка коротила в «прошло», и один зелёный флаг мог быть привязан к НЕ-интеграционной ревизии; теперь
без реального integration-SHA доказательство не считается относящимся к интеграции и PR не открывается.
Проверка write_scope перестала ложно валить хорошую работу: каталог-запись без wildcard или с завершающим
слэшем (`quality`, `src/`) теперь сопоставляется по префиксу, как в планировщике, поэтому легитимно
изменённый `quality/foo.py` больше не помечает пакет нарушителем. Force-push интеграционной ветки идёт
через `--force-with-lease` и его результат проверяется — при неуспехе возвращается явная ошибка, а не
проглатывается с последующей запутанной ошибкой открытия PR. И послабление для churn в `.ai/` при
preflight теперь действительно исполняется: путь из porcelain-строки сверяется по началу, а не по концу
(строка кончается именем файла), так что задуманное исключение работает, а не остаётся no-op.
