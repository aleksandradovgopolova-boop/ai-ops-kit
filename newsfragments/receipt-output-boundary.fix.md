Проверка Kit различает свои объявленные outputs и значимые входы: создание Hypothesis-кэша не скрывает успешный результат, а последующая подмена кэша требует проверки заново. Новые записи сохраняют причину изменения входов. Тяжёлый локальный запуск использует общий для checkout’ов host-slot; внешним self-hosted runner нужен явный вызов этого wrapper.
