Roadmap теперь связывается с milestones и backlog в прослеживаемую цепочку направление→milestone→
задачи (PR-7). Новый модуль `ai_ops_kit/planning/roadmap_milestones.py` связывает выведенный roadmap
с задачами по КОНТРАКТУ ДАННЫХ ленты 3 (не читает GitHub и не лезет в её модули): milestone
привязан к направлению через `roadmap`-ссылку или через задачи в нём, задача — напрямую или через
milestone. Разрыв цепочки виден как находка отчёта: направление в Now без milestone, milestone без
задач, висячая ссылка на несуществующее направление, сирота-задача. Третье состояние сохранено:
«источник backlog не подключён» ≠ «backlog пуст».
