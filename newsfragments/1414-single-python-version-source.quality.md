Версия Python теперь задаётся в одном месте — файле `.python-version` — и для локальной разработки, и для проверок (CI читает тот же файл через `python-version-file`). Раньше версии локально и в проверках могли молча разойтись (напр. 3.14 против 3.12), из-за чего зелёное локально краснело в проверках; теперь источник один, расхождению неоткуда взяться, и отдельный тест стережёт, чтобы пин не разъехался с полом `requires-python`. Быстрые локальные прогоны по умолчанию берут закреплённый проектный `.venv`.
