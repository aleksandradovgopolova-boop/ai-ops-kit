Генератор точек входа рантайма стал по-настоящему runtime-агностичным: набор рантаймов теперь
берётся из `registry/runtimes.yaml` (все с `adapter_depth: generated-commands`), а не из захардкоженной
пары. Новый рантайм подключается объявлением в реестре плюс профилем рендера — без правки логики
генератора. На этом заведён адаптер **Qwen Code**: кит генерирует его слэш-команды (`.qwen/commands/`,
markdown + YAML-фронтматтер, как принято у Qwen Code) и ставит их при установке, если рантайм включён
в `.ai-ops.yaml`. Глубина адаптера честная: `generated-commands` — кит генерирует точки входа, а стадии
и блокировку гейтов исполняет сам Qwen Code; полное исполнение контракта с enforcement гейтов
по-прежнему через generic-orchestrator. Claude Code и Codex работают как раньше (вывод для них не
изменился) — теперь просто через общий, управляемый реестром путь.
