Путь «понял проект → есть работа» называет команды, а не «скажи мне» (второй живой проход человеком, фаза работы). Раньше `bootstrap` рекомендовал создать план, но команду `--apply` не называл — человек не знал, как сказать «согласен», и застревал в петле; а `next` при пустом/примерном плане звал расплывчато («скажи — соберу план», «создам черновик, если скажешь»). Теперь: сухой `bootstrap` ведёт действием «создать план: `./ai-ops bootstrap --apply`»; `next` называет конкретный путь «`./ai-ops model` (ответь) → `./ai-ops bootstrap --apply`». Проверено на реальном репозитории: next → bootstrap --apply → next даёт работу.
