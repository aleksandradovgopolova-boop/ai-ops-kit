Сверка приёмки больше не проваливается, когда независимый судья выносит корректный вердикт прямо из
диффа, не открыв файл отдельным шагом. Раньше вердикт без единого чтения СУДЬЁЙ считался рубер-штампом
и обнулялся — и на живых прогонах это делало чистую приёмку авто-судьёй недостижимой: судья судил
верно, но «церемониального» чтения не делал. Теперь авторитетное чтение доставленного файла делает
САМ КИТ и подтверждает каждую цитату по эталону; смысловой вердикт остаётся за независимым судьёй.
Это одновременно СТРОЖЕ прежнего: «выполнено», чья цитата есть в диффе, но отсутствует в доставленном
файле (устаревший или частичный дифф), больше не принимается — рубер-штампом теперь считается вердикт,
не сверенный с доставленным файлом ничем.
