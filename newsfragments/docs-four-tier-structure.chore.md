Документация разложена по четырём уровням — START (первый день), USE (каждый день),
EXTEND (расширяете кит), ARCHITECT (проектируете вглубь). Новичку виден понятный путь: чтобы
начать, `AGENTS.md` читать не нужно. Главная страница и навигация ведут по уровням, каждая
существующая страница остаётся достижимой; API-справочник и записи о прошлом помечены отдельно.
