Гейт параллельной безопасности пропускает собственные install/update-PR кита без ручного шага: признак апдейта (по умолчанию `.ai/managed/VERSION`) теперь объявлен ДАННЫМИ в `registry/coordination-files.yaml` (`kit_update_markers`), а не зашит в коде — реестр остаётся источником истины, дочка расширяет список своим. Первый заезд кита на репозиторий без кита и любой апдейт с миграцией плана проходят `--strict` без ручного `git rm` координационных файлов; обычный PR, смешавший код с планом, по-прежнему валится (#764, #384).
