Первый час: `./ai-ops model --answer <id> "<ответ>" [--why "источник"]` записывает ответ онбординга без ручной правки `.ai/project/onboarding-answers.yaml`. Ответ становится подтверждённым фактом (`user_confirmed`), уходит из пакета открытых вопросов и больше не переспрашивается; `--why` ложится комментарием-основанием (тот же механизм, что комментарии владельца). Несуществующий вопрос отвергается со списком доступных. Прямая цель ROADMAP «владелец больше не обязан править YAML руками» (issue #612, срез 1). Док `docs/ONBOARDING.md` и плагин-скилл переписаны на реальный поток model → answer → bootstrap → next (раньше просили «заполнить context/ руками»).
