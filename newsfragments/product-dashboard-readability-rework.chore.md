Продуктовый пульт переработан для продакт-аудитории: ёмкое описание продукта из README вместо
внутреннего принципа, одноколоночная раскладка (описание → метрики → пульс → роадмап → задачи →
артефакты), семейство метрик TTVO вместо одной цифры, понятный «Пульс продукта» («первые данные ·
n=4» вместо «неизвестно»), разделы открываются модалкой со ссылкой в репозиторий, честные подписи
паспорта («кит вывел сам» / «только владелец знает»). Роадмап переписан в бизнес-формулировки в
ROADMAP.md (техдетали сохранены под заголовками). Встроенный в `index.html` снимок теперь
синхронизируется генератором при каждой сборке, поэтому пульт не отстаёт при локальном открытии.
