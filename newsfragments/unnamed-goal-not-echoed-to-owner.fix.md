Продуктовые поверхности больше не показывают человеку внутренний id-заглушку цели. На свежей установке bootstrap рисует направления с черновыми именами `goal-id-1`/`goal-id-2`, и `propose`/`next` echo'или их дословно — «начать двигать направление «goal-id-1»»: внутренний id трубопровода в лицо владельца (нашла репетиция чистой установки 16.09). Теперь, пока у цели нет заданного человеком имени, кит называет её **«безымянное направление (задай имя через `ai-ops model`)»** и подсказывает, чем это чинится, — а сам id в данных не трогает. Задал имя через `ai-ops model` — направление зовётся по имени.
