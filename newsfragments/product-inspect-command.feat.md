`ai-ops inspect <id>` — карточка одного продукта флота по id, без cd в его репозиторий. Показывает
полный контракт (стандарт, артефакты, источники истины контуров), вердикт, живое здоровье и риски —
всё, что даёт `ai-ops contract`, но по любому продукту реестра флота из одного места. Неизвестный id
честно называет известные, а не выдумывает продукт. id — единственный аргумент (модель CLI отдаёт
один токен задачи, и inspect в неё ложится чисто; register/fleet живут под `products`, а inspect —
отдельной командой). Только чтение; health/risks впрыскиваются сверху, как в contract.
