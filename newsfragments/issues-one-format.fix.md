Все issue кита заводятся в одном формате: заголовок `<slug>: <исход>` и четыре секции — Что / Зачем / Проверяемо / Границы/Источник. Прежде шаблону следовали 4 из последних 150 issue: ночная сверка роадмапа и сверка задач-кандидатов писали каждая по-своему, а агентам правило никто не называл. Теперь оба генератора собирают issue одним модулем, у направлений появился шаблон эпика, пустое issue без шаблона завести нельзя, а расхождение шаблонов с кодом ловит тест. Заголовки уже заведённых issue не переписываются — новый формат получают новые issue.
