Убран рецидивирующий флак CI. Тесты, которые git-init'ят репозиторий и потом копируют его целиком
(`shutil.copytree` каталога с `.git`), ловили гонку: git после commit запускал фоновую обслуживание,
та создавала и тут же удаляла `.git/objects/maintenance.lock`, а параллельный copytree под xdist падал
на исчезнувшем файле (`test_update_policy_enforcement`, `test_command_language_wiring` — мигали в
группах fast и coverage, требуя перезапуска). Это не дефект продукта, а фоновой git против copytree.

`tests/conftest.py` через переменные `GIT_CONFIG_*` выключает `maintenance.auto` и `gc.auto` на каждый
git-подпроцесс тестов: локов больше не появляется, копировать нечего ловить. Ни один тест не зависит
от фоновой уборки git — снимается только источник гонки.
