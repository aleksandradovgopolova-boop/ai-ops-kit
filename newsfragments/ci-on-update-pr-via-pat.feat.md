Доставляемый workflow автообновления (`ai-ops-update.yml`) теперь может запускать **CI на update-PR**: если задан secret `AI_OPS_PAT` (fine-grained PAT или токен GitHub App с правами contents+pull-requests), checkout/push/PR идут под ним, и обычные проверки дочки (`on: pull_request`) на update-PR стартуют штатно — а значит авто-мержу патчей есть чего ждать. Без секрета поведение прежнее (PR открывается, но CI на нём GitHub сам не запускает), и об этом печатается явная подсказка (#930).
