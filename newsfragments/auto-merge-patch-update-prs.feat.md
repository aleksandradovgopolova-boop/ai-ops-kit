Доставляемый workflow автообновления (`ai-ops-update.yml`) теперь умеет **авто-слияние патч-версий** update-PR: при `parent.auto_merge_patch: true` патч-обновление (совпадают major.minor, растёт patch) сливается само через `gh pr merge --auto` — после обязательных проверок ветки. По умолчанию флаг ВЫКЛ (слияние в main сильнее, чем открыть PR); минор и мажор всегда остаются на ревью; мгновенный обход проверок (`--admin`) не используется (#927).
