CI-шаблоны кита, поставляемые дочкам, получили отмену устаревших прогонов и кэш npm (полевая находка ии-среда 2026-09-16: этих блоков не было ни в одном шаблоне, из-за чего прогоны копились в очереди). Во все 11 workflow добавлен `concurrency` с БЕЗОПАСНОЙ отменой — гасятся только PR-прогоны (новый пуш в PR отменяет прежний), а push в main / schedule / release / record НЕ отменяются (потеря такого прогона = дыра в проверке или записи). Превью Storybook кэширует npm при наличии lock-файла (без него не включается, чтобы не сломать проекты без lock). Зафиксировано тестами.
