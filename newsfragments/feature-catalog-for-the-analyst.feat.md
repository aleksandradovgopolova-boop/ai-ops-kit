Каталог фич для аналитика: генератор `ai_ops_kit/checks/feature_catalog` собирает из реестра фич человекочитаемый каталог (`docs/feature-catalog.md`) — по каждой фиче что делает / для кого / как проверить, поверхности с уверенностью и статус, чтобы разобраться во всех фичах продукта из одного места. Значения выведены из реестра при генерации (как `docs/capability-map.md`), а не написаны руками; чистый рендер доставляется в дочку, поэтому её аналитик генерирует свой каталог из её собственного реестра.
