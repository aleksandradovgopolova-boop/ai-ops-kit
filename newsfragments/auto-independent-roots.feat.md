Опциональный `session_economy.auto_parallel_independent_roots: true` проводит обычный `do`/`run --execute` через существующий parallel runner: сохранённый WorkGraph своей работы, задачи из настоящих WorkItems, независимые конкретные области и максимум два активных пакета. Один объявленный `max_model_calls` общий для всех ролей; canonical Git-common claim сохраняет frozen inputs/base/identity и блокирует дубли, включая обычный single-run. Исходные планы сохраняются; fan-in проверяет итоговый SHA/tree.

По умолчанию выключено; `--sequential` отключает автоматический выбор, явный `--parallel` сохраняется. Первый срез требует сохранённых WorkItems/RunPlans/run-settings, текущей базы и контрактов уже в базе. Зависимые пакеты, globs, неподдержанные session/global/USD/duration ceilings и неоднозначная политика отказывают до клонов/моделей. Controlled transport tests не означают live product acceptance; native сессии и hard global quota этим срезом не реализованы.
