Извлекатель поверхностей продукта теперь видит СЕРВЕРНЫЕ маршруты JS/TS-бэкенда (вид `route`) для
Express, NestJS и Next. Express и Nest разбираются детерминированно по тексту (вызовы `app.get(...)` /
декораторы `@Get(...)` + `@Controller(...)`), Next — структурно из раскладки файлов (`pages/api/**`,
`app/**/route.ts`), без исполнения node и без сети. Разбор текстовый/файловый, а не доказательный AST,
поэтому такие маршруты помечаются `inferred` (видны в каталоге, но прогон не блокируют).
