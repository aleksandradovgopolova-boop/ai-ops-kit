Внутренний ревьюер кита теперь может САМ закрыть блокирующий гейт обоснованным «pass». Живой прогон против внешнего репозитория вскрыл два дефекта, оба устранены: (1) на claude-cli-пути дифф даётся ревьюеру инлайном (op:read он не шлёт), а прошлая элицитация уводила в прозаический pass без цитаты — который честностный страж держал как рубер-штамп, поэтому pass на блокирующем гейте нельзя было заземлить в принципе; теперь для pass требуется одна лёгкая цитата на изменённый файл (needs_work/fail остаются простой строкой, анти-таймаут сохранён). (2) На переоценке гейт спецификации при валидном openspec терял доказательство requirements_covered (асимметрия с авторингом) и ронял чистую правку кода — теперь отдаёт оба доказательства. Инвариант «pass без заземления не закрывает гейт» не ослаблен (#587).
