Восьмое состояние знания **CONFLICTING**: когда источники истины об одном факте противоречат
(README называет одну СУБД, ARCHITECTURE — другую, зависимости кода — третью), `ai-ops model`
не выбирает сторону молча, а объявляет «источники противоречат, актуальный определить не могу» с
перечислением каждого голоса. Детектор поднимает состояние только при доказуемом расхождении;
явное подтверждение владельца разрешает спор. Trust layer: кит честен про то, чего не знает
наверняка (#634).
