Извлекатель поверхностей продукта научился видеть **экраны Angular Router** (вид `screen`): из TypeScript детерминированно и без исполнения читаются маршруты `RouterModule.forRoot([{ path: 'billing', … }])` / `.forChild([...])` и `const routes: Routes = [{ path: 'x' }]` — литеральный путь нормализуется к `/billing` для единообразия с react/vue. Разбор сужен к индикатору Angular (`@angular/router` / `RouterModule` / аннотация `: Routes`), чтобы чужой объект с ключом `path:` не дал ложный экран. Как у react/vue-router, это текстовый (не AST) разбор → `confidence: inferred` (в каталог попадает, прогон не блокирует). Осознанно НЕ выводятся: lazy `loadChildren`, wildcard `**`, пустой/динамические/матричные пути и standalone-роуты `provideRouter` при нелитеральном массиве.
