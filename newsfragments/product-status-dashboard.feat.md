Появился разворачиваемый пульт состояния кита для владельца-продакта: паспорт продукта,
здоровье, дочки и ближайшие задачи на одном экране (тёмная тема). Числа читаются вживую из
`dashboard/data.json`, который собирает `dashboard/build_data.py` из источников истины
(VERSION, реестр, гейты) и открытых задач; что не доказано из источника — помечается как
недоказанное, а не выдумывается. Рабочий процесс `status-dashboard` освежает и публикует
пульт на GitHub Pages сам — по расписанию, при изменениях в `main` и по ручному запуску.
