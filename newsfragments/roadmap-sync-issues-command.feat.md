Новая команда `roadmap sync-issues`: сводит GitHub Issues с роадмапом одной командой — эпик на
каждое открытое направление («Сейчас»/«Следующий») и подзадача на каждую незакрытую работу плана,
связанные task-list'ом. Правило «каждое направление всегда имеет issue» теперь держит механизм, а не
память агента. По умолчанию — сухой прогон (показывает, что завести/обновить/закрыть); применяет
`--apply`. Идемпотентна и усыновляет уже заведённые вручную issue по ключу, а не плодит дубли; нет
доступа к GitHub — честное «не проверено» (код 2), а не пустой план. Ядро сверки — чистая функция на
инъектируемом порте (тестируется без сети), `gh` живёт в адаптере CLI.
