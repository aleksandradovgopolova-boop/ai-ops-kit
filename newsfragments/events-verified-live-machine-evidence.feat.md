`event_arrival.events_verified_live()` производит машинное доказательство гейта
`analytics_runtime_verification` из выгрузки поступления, а не из декларации судьи: три
честных состояния (met / НЕ met / unknown при отсутствии выгрузки), CLI `event_arrival
--evidence`. Замыкает разрыв «доказательство объявлено mechanizable, но его давала декларация».
