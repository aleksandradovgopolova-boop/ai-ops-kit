В начале README появилась одна фраза о том, чем Кит отличается от AI-агента, который просто пишет код: он хранит, почему продукт устроен именно так, — связь изменения с решением, доказательством и, где результат измерен, с тем, что изменилось для пользователей (#1142). Обещание намеренно не шире доказанного: оговорка «там, где результат измерен» остаётся, пока доля работ с измеренной пользой для дочки честно низкая.
