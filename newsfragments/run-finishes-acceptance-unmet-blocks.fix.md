Прогон блокирует ready при невыполненных критериях приёмки (болезнь A из наблюдения 12.08).
Если acceptance_verify СОСТОЯЛАСЬ (verified=True) и есть unmet критерии — ready_for_pr=False.
Модель больше не может объявить успех при незакрытой основной части задачи. Если сверка не
состоялась (verified=False) — не блокируем (advisory, как было). Болезнь B (подгонка теста
под сделанное) остаётся открытой — требует сверки теста с КРИТЕРИЕМ, а не с кодом.
