AI Ops читает GitHub Issues как операционную единицу backlog и наводит на них порядок. Задачи
классифицируются по типу (feature/bug/research/improvement/tech-debt/experiment/infrastructure),
области и атрибутам; находятся дубликаты (кит их ПРЕДЛАГАЕТ объединить, а не сливает молча) и
устаревшие; считается приоритет и строится граф зависимостей (блокирующие, критический путь,
скрытые и циклические). Каждый вывод объясним: приоритет и подозрение в дубле называют, ПОЧЕМУ они
такие. Доступа к GitHub нет — кит честно говорит «не проверено» с причиной, а не выдаёт пустой
результат за «задач нет». Без новых зависимостей: `gh` или `urllib`.
