# standards/architecture — Архитектурная конституция кита (источник)

Единый **источник** правил о том, **как НЕ писать код и как НЕ строить архитектуру** — машиночитаемо
и проверяемо, а не только текстом-подсказкой. Проектно-агностична: статьи про монолиты, god-функции,
циклы зависимостей, мёртвый код и ложную зрелость вообще, а не про конкретные файлы.

## Один источник, два генерируемых представления

| Файл | Что это | Правится руками? |
|---|---|---|
| `ARCHITECTURE_CONSTITUTION.md` | **Источник истины**: 37 статей (преамбула Честность + I Архитектура + II Код + III Безопасность + IV Данные и API-контракты), стабильные ID `HON-`/`ARCH-`/`CODE-`/`SEC-`/`DATA-` | да — правило меняют здесь |
| `arch.rules.md` | Оперативный слой: одна строка на правило, для контекста агента | **нет — генерируется** |
| `rules.yaml` | Машинный реестр для доставки, гейтов и валидаторов | **нет — генерируется** |
| `scripts/build-rules.py` | Генератор обоих представлений из Конституции | — |
| `research-checklist.md` | Ресёрч-основа (Cursor rules / clean-arch / security), на которую опираются статьи (#822) | да |

`arch.rules.md` и `rules.yaml` **собираются** из `ARCHITECTURE_CONSTITUTION.md`. Ручная правка
генерируемого файла затирается пересборкой, а расхождение краснит контур (зеркало-тест
`tests/unit/test_architecture_constitution_source.py`) — по образцу uiux-стандарта.

## Честность как поле, а не декларация

Каждая статья несёт машинное поле **`enforced_in`** — где её гейт реально гоняется:

- `parent` — только в CI кита (в дочку не едет);
- `child` — едет и гоняется в дочке;
- `both` — и там, и там;
- `none` — гейта нет (честный **долг**, а не защита);
- `meta` — само-правило о правилах.

Это принципиально: многие структурные гейты кита (`validate_layering`, `validate_func_size`,
инвентарь built≠wired) — **parent-only**. Выдавать их за защиту дочки запрещено (`HON-003`). Разрыв
«есть правило, но в дочке не гоняется» — это долг, отслеживаемый в #827; карта соответствия статья↔
гейт — в #824.

## Изменить правило

1. Правишь `ARCHITECTURE_CONSTITUTION.md` (ID стабильны — на них ссылаются гейты; новое правило
   получает следующий свободный ID, старые не перенумеровываются). Машинные поля (`Уровень`,
   `Категория`, `Severity`, `Гейт`, `Исполнение`) — из замкнутых словарей; генератор краснеет на
   значении вне словаря.
2. Пересобираешь:

   ```bash
   python standards/architecture/scripts/build-rules.py
   ```

3. Коммитишь источник вместе с пересобранными `arch.rules.md` и `rules.yaml`. Зеркало-тест не даст
   закоммитить рассинхрон.
