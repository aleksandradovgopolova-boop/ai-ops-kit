# Ресёрч-основа Архитектурной конституции (#822)

Свод лучших источников (Cursor rules, AGENTS.md-стандарт, Clean Architecture / SOLID, code-smells,
security-baselines) в проектно-агностичный чек-лист, на который опираются статьи конституции.
Для каждого пункта: анти-паттерн, подсказка агенту в момент письма, класс исполнения (гейт /
advisory). Материал адаптирован, не скопирован.

## Сквозная тема: «правило без гейта — пожелание»

Главный вывод по всем источникам: правила делятся на два класса исполнения, и честный стандарт
**помечает, какой именно**.

- **Гейт (машинно-проверяемо):** линтер, тайпчекер, тест, CI-проверка или pre-write-хук механически
  отклоняет нарушение (например, secret-scan + push protection, детектор длинных функций/дублей).
- **Advisory:** сформулировано как директива, направляющая генерацию, но соответствие подтверждает
  только человек-ревьюер или сам агент. Cursor/AGENTS-правила — это system-message-подсказки; они
  смещают вывод, но не enforce.

Следствие для конституции: каждая статья несёт и подсказку в момент письма, и механизм исполнения;
где гейта нет — сказано прямо (`enforced_in: none`), а не выдано за защиту. Это ровно принцип кита
«недоказанное называется недоказанным».

Отдельный класс — **анти-паттерны, специфичные для агентов** (которых нет в человеческих
методичках): анти-галлюцинация (не выдумывать API/сигнатуры/импорты), не тянуть deprecated, «не
извиняйся — чини».

## Формат доставки (из конвенции AGENTS.md)

- **AGENTS.md** — открытый стандарт файла инструкций агенту (формализован 2025, плоский Markdown,
  иерархичен — ближайший в дереве побеждает). Кит НЕ пишет в AGENTS.md дочки (её дочка владеет);
  подсказки доходят машинным реестром + цитированием ID в чек-листах/ревьюерах.
- **Cursor `.cursor/rules/*.mdc`** добавляет scoping (glob-таргетинг, always-on vs agent-requested) —
  полезно, если правило нужно привязать к путям.
- **Фразировка, которая направляет агента:** императивные, блокирующие директивы + пара
  «плохо/хорошо» работают лучше прозы («избегай X», «обрабатывай ошибки сверху ранними возвратами»,
  «не выдумывай сигнатуры», «все тесты зелены до мержа»).
