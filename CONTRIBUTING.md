# Вклад в AI Ops Kit

**Русский · [English](CONTRIBUTING.en.md)**

Сообщения о проблемах и улучшения документации можно писать по-русски или
по-английски. Для ошибки укажите версию кита, ОС/Python, команду, ожидаемый
результат и обезличенный фактический вывод. Не прикладывайте секреты.

Коммерческое использование текущего кода требует отдельной лицензии;
[условия и связь с автором](README.md#лицензия). Ранее опубликованные версии
до 4.12.0 включительно сохраняют MIT. Эта страница не меняет условия LICENSE.

Перед изменениями прочитайте [AGENTS.md](AGENTS.md) и
[инженерный цикл](docs/agent-guides/engineering-cycle.md). Используйте отдельную
ветку/рабочую копию, заявите область записи и начните с короткого Change Brief.
Код, реестры и ссылки должны оставаться согласованными; новый runtime нельзя
объявлять поддерживаемым без проверки. Русская и английская входные страницы
должны сохранять одинаковое содержание. Внутренняя документация пока преимущественно русская.

Среда разработки из корня checkout:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements-dev.txt
./scripts/check-fast.sh
```

Проверка выбирает охват по diff относительно `origin/main`; это локальная
проверка, не замена обязательного CI. Для изменения примера запустите
`python3 examples/first-session/demo.py`. Для документации проверьте ссылки
и оба языка. Добавьте [newsfragment](newsfragments/README.md); VERSION и
CHANGELOG меняются при выпуске, а не при каждой правке.

Задачи оформляются по [шаблону](.github/ISSUE_TEMPLATE/task.md): что, зачем,
как проверить, границы/источник. Для PR укажите проблему, итоговое поведение,
проверки и ограничения; не смешивайте чужие изменения. До слияния нужны
независимое ревью и применимые проверки CI точного итогового изменения.
