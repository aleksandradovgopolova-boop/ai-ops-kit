# Команда: ai-verify

## Назначение

Проверить доказательства выполнения критериев.

## Порядок выполнения

1. Сопоставить каждый критерий с проверкой.
2. Выбрать проверки по полному diff и текущей стадии через существующий
   `verification_tiers` / `evidence_collector`. Действительный PASS с совпадающими входами,
   зависимостями, инструментами и средой переиспользовать через существующий механизм receipts.
   Запустить только отсутствующие, неприменимые к текущим входам или ранее упавшие проверки.
   Без подтверждённого адаптера окружения результат исполняется заново. Итерационный охват
   не заменяет обязательные проверки merge/release.
3. Зафиксировать результаты и непроверенные области.
4. Передать Final Verifier собранные доказательства с названным охватом. Дополнительный
   запуск нужен для конкретного непокрытого риска или изменившихся входов; сама передача
   результата другому агенту или смена стадии не требует повторять ту же команду.
5. **Записать срез эффекта**: `PYTHONPATH=.ai/managed python3 -m ai_ops_kit.lifecycle.run_report features/<id> --record` (автонакопление истории).

## Результат

VerificationEvidence и финальный вердикт.

## Ограничения

Не считать текстовый отчёт другого агента доказательством без проверяемого результата.
Проверяемый receipt проверяется на применимость, а не заменяется повтором лишь потому,
что его получил другой агент. FAIL/SKIP/BLOCKED и неполные записи не разрешают reuse.
