# Команда: ai-regression-check

## Назначение

Определить и выполнить минимальный достаточный regression scope.

## Порядок выполнения

1. Проанализировать diff и зависимости.
2. Выделить затронутые сценарии.
3. Сформировать набор проверок.
4. Проверить применимость существующих receipts для выбранного набора. Выполнить только
   проверки без действительного PASS на текущих входах; при неизвестном влиянии использовать
   полный профиль. Не дублировать уже исполненную команду из ai-verify без нового основания.
5. Зафиксировать residual risk.

## Результат

Regression Scope и Test Report.

## Ограничения

- Соблюдать scope, evidence policy и human approvals.
